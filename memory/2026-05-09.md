# 2026-05-09 — Cot项目液冷机掉线处理策略分析

## 液冷机协议关键发现

- **英维克 A8 协议**位于 `projects/cot/docs/protocols/README.md` 2.6节
- 液冷机出厂为**全自动模式**（0x0401=4），掉线后设备大概率仍在自主运行
- **关键陷阱寄存器 0xE617**（通信中断后制冷加热点复位）：
  - 0=不复位（推荐）
  - 1=复位（危险，掉线后温度设定回到默认值，可能导致电池舱过热）
  - **必须确认4台液冷机均设为0**

## 分级处理策略框架（已提出，待用户确认）

| 场景 | 判定条件 | EMS动作 |
|------|---------|---------|
| 场景A | 心跳3~5周期无响应 + BAM电池温度<45℃ | L3告警，维持运行，缩短BAM温度巡检至1s |
| 场景B | 心跳超时 + BAM温度≥45℃且持续上升 | 对应簇PCS降功率50%，尝试重连RS485 |
| 场景C | 0xE715≥2（出水高温/缺水/高低压锁定） | 立即告警，对应簇限功率运行，评估切除 |
| 场景D | BAM地址43=5/6/7/8（禁充/禁放/故障） | 遵守BMS边界，该簇PCS立即停机 |

## 状态机衔接建议

- **液冷机通信中断不应触发C2进Fault态**
- C2应限定为：PCS、BAM、STS、关口表通信中断
- 液冷机、除湿机、变压器温控仪通信中断只走L3告警通道

## 并柴发态特殊处理

- 并柴发时柴发宝贵，优先保负载
- 液冷机掉线但BAM温度<45℃ → 维持该簇运行
- 45~50℃ → 该簇PCS降功率30%，柴发补缺口
- ≥50℃或温升>2℃/min → 切除该簇

## 待确认事项（已提出给用户）

1. 0xE617是否已设为0=不复位
2. 液冷机掉线是否同意不进C2（只走L3告警）
3. BAM单体温度精度及电池规格书工作温度上限
4. RS485-7总线故障与单台设备故障的区分策略

## 拓扑自检记录

```
液冷机1# → DC柜1# → 电池1# → BAM1 (簇1)
液冷机2# → DC柜2# → 电池2# → BAM1 (簇1)
液冷机3# → DC柜3# → 电池3# → BAM2 (簇2)
液冷机4# → DC柜4# → 电池4# → BAM2 (簇2)
```

液冷机与DC柜一一对应，单台掉线影响对应簇，需联动BAM温度做间接温控监控。

### 关键设备（进C2）最终清单

PCS(1#~5#)、BAM(1~2)、STS、关口表、储能表、负载表、柴发表

### 非关键设备（走L3，不触发状态机）

液冷机(1#~4#)、除湿机(1#~4#)、变压器温控仪(1台)

### 设计理由

- 液冷机为**全自动模式**，掉线后设备大概率仍在自主运行，不因通信中断就停机
- 系统通过**BAM电池温度**间接监控热管理状态，温度失控再走BMS边界保护
- 避免"一台液冷机掉线导致整个站停"的非必要停机
- 并柴发态下优先保负载，不因液冷通信中断切除柴发负荷

### 液冷机分级处理策略（已定稿）

| 场景 | 判定条件 | EMS动作 |
|------|---------|---------|
| **场景A** | 液冷机通信中断 + BAM温度<45℃ | L3告警，维持运行，BAM温度巡检缩至1s |
| **场景B** | 液冷机通信中断 + BAM温度45~50℃ | 对应簇PCS降功率30%，RS485重连尝试 |
| **场景C** | 液冷机通信中断 + BAM温度≥50℃或温升>2℃/min | 切除该簇，告警升级 |
| **场景D** | 0xE715≥2（出水高温/缺水/高低压锁定） | 对应簇PCS限功率运行，评估切除 |
| **场景E** | BAM地址43=5/6/7/8（禁充/禁放/故障） | 遵守BMS边界，该簇PCS立即停机 |

### 协议寄存器关键值

- **0xE617 = 0**（通信中断后制冷加热点不复位）— 必须确认4台均为0
- **0x0401 = 4**（全自动模式）— 掉线后自主运行
- **0xE715** — 告警最高等级，≥2时锁定运行
