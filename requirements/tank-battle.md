# 需求：坦克大战（Windows 可运行）

## 目标
用 Python + Pygame 实现一个可玩的坦克大战游戏，最终交付 Windows 可执行程序或源码包。

## 核心玩法
1. 玩家控制绿色坦克（方向键/WASD移动，空格射击）
2. 敌方红色坦克自动巡逻，发现玩家后追击射击
3. 地图有砖墙（可摧毁）、钢墙（不可摧毁）、水域（坦克不能过，子弹能过）
4. 玩家基地（鹰标志）被摧毁 = 游戏结束
5. 消灭所有敌方坦克 = 过关

## 技术需求
1. 窗口 800x600，网格 26x20（每格 32x32 像素）
2. 60 FPS，流畅碰撞检测
3. 坦克有冷却时间、无敌闪烁、生命数
4. 敌方坦克分普通/快速/重型三种
5. 爆炸动画（粒子效果）

## 文件结构
```
tank-battle/
├── main.py           ← 入口
├── game.py           ← 游戏主循环/状态管理
├── tank.py           ← 玩家/敌方坦克类
├── bullet.py         ← 子弹类
├── map.py            ← 地图/瓦片系统
├── enemy_ai.py       ← 敌方 AI 行为
├── assets/           ← 图片资源（可用彩色矩形替代，优先可运行）
└── levels/
    └── level01.txt   ← 关卡地图（字符矩阵）
```

## 关卡地图字符定义
- `.` = 空地
- `#` = 砖墙（1 发子弹摧毁）
- `@` = 钢墙（不可摧毁）
- `~` = 水域
- `P` = 玩家出生点
- `E` = 敌方出生点
- `B` = 基地（必须保护）

## 质量要求
- 类型注解
- 清晰的游戏状态机（MENU → PLAYING → GAME_OVER → VICTORY）
- 音效占位（用 print 或简单 beep）
- README 包含运行说明和依赖安装命令
- 优先保证可运行，美术用彩色几何图形替代

## Windows 交付物
- 方案 A（优先）：源码 + `pip install -r requirements.txt` 即可运行
- 方案 B（如果时间允许）：PyInstaller 打包为 single .exe

## 敌方 AI 行为
1. 随机方向移动，遇墙/边界转向
2. 每 2 秒随机转向一次
3. 视野内发现玩家（前方 5 格直线）→ 朝向玩家方向并持续射击
4. 三种类型：
   - 普通：1 血，慢速，灰色
   - 快速：1 血，快速，黄色
   - 重型：3 血，慢速，红色，子弹可穿透砖墙
