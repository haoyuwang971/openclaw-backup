## 1. 产品概述

### 1.1 产品定位

**Cot EMS** 是一套面向缅甸地区光储柴微网场景的能源管理系统，部署于 WL-EMS-1000-M 边缘控制器，实现储能、光伏、柴发的协同控制，确保系统在并网/离网/并柴发模式下的稳定运行。

> **国标定位**：依据 GB/T 36274-2018 第3.1条，微电网EMS是"用于微电网运行控制和能量管理的系统"；本项目属于"光储柴混合微电网"类型。

### 1.2 核心价值主张

| 价值维度 | 描述 | 国标依据 |
|----------|------|----------|
| **绿电最大化** | 优先消纳光伏，减少化石能源依赖 | GB/T 36274 第5.1条：能量优化调度目标 |
| **供电可靠性** | 市电中断时无缝切换至储能/柴发，保障重要负载 | GB/T 33589 第4.2条：微电网供电可靠性要求 |
| **运维智能化** | 本地+云端双通道监控，支持远程策略下发 | GB/T 42726 第5.3条：远程监控与运维要求 |

### 1.3 目标用户画像

|----------|----------|----------|----------|
| **现场运维工程师** | 设备安装调试、故障排查 | 本地屏幕操作、实时数据查看、手动控制、模式切换 | GB/T 42726 第5.4.2条：就地操作功能 |

```
┌─────────────────────────────────────────────────────────────────┐
│                         交流母线 (AC Bus)                        │

│  │(375kW)  │    │(250kW)  │    │         │                     │
│  └────┬────┘    └────┬────┘    └─────────┘                     │

│  └──────────┘    └──────────┘    └──────────┘                  │
└─────────────────────────────────────────────────────────────────┘
```

**拓扑特征**:
- **两簇PCS交流侧并联**，共接交流母线，与负载、STS连接（GB/T 36558 定义的"交流端口并联"结构）
- **每簇独立直流母线**：MPPT、电池、PCS直流侧**并联在直流母线上**（GB/T 34120 定义的"直流母线并联"拓扑）
- **⚠️ 关键约束**: MPPT直流输出直接到直流母线，与电池并联（**不经过PCS**）。MPPT与PCS在直流母线上为并联关系，非串联。
- **直流侧功率平衡**: `P_bat = P_pv - P_clu/η`
  - `P_bat`：电池充放电功率（正=充电，负=放电）
  - `P_pv`：MPPT总输出功率（始终为正）
  - `P_clu`：PCS簇总功率（正=放电逆变，负=充电整流）
  - `η`：PCS转换效率
- **ATS**：市电优先级高，保证单电源输入（市电/柴发二选一，符合 GB/T 33589 要求）
- **STS**：控制并网/离网切换（符合 GB/T 36274 微网状态切换要求）

### 2.2 簇定义

| 簇 | PCS | MPPT | DC柜 | BAM | 额定功率 |
|----|-----|------|------|-----|----------|
| **簇1** | 1#~3# | 1#~4# | 1#~2# | BAM1 (TCP1) | PCS: 375kW / MPPT: 400kW / 电池: 260kW |
| **簇2** | 4#~5# | 5#~7# | 3#~4# | BAM2 (TCP2) | PCS: 250kW / MPPT: 300kW / 电池: 260kW |

## 3. 用户故事 (User Stories)

### 3.1 绿电消纳场景

> **作为** 能源管理专员，  
> **我希望** 系统优先使用光伏发电供负载，多余电量充入储能，不足时储能放电补充，  
> **从而** 最大化绿电消纳率，减少从电网购电。

**前置条件**：绿电阈值设置为 **90%（滞环±2%，即92%开启放电，88%停止放电）**

**验收标准**:
- 当两簇最小SOC ≥ 绿电阈值(92%)且并网时，通过PCS做负载跟随：
  - 当 PV总功率 ≥ 负载功率时，光伏通过直流母线直接给电池充电（PCS功率=负载功率×95%）
  - 当 PV总功率 < 负载功率时，PCS放电补充缺口（PCS功率=负载功率×95%）
- 当两簇最小SOC < 绿电阈值(88%)时，不通过PCS进行放电：
  - PV通过直流母线直接给电池充电（PCS功率=0），负载交给市电
- 每簇PV功率限制值 = 95% × (簇电池总充电需求 + 簇PCS总实时功率)
  - 注：此公式基于直流侧功率平衡 P_bat = P_pv - P_clu/η
- 关口表功率 > 防逆流余量（5kW），EMS限制PCS放电功率使逆向功率 ≤5kW（防逆流阈值5kW为项目自定义值，国标仅要求配置逆向功率保护功能，见GB/T 43526-2023 第10.7条）
- 功率调节周期 ≤ 2s（GB/T 36558-2023 第5.2.3条功率调节时间要求）

**异常分支**:
- 若SOC达到上限（95%），停止充电，多余PV功率限发
- 若SOC达到下限（20%），停止放电，电池从电网充电(若并网)

> **国标依据**: GB/T 36274-2018 第5.1条"能量优化调度"要求微网EMS应实现分布式电源出力最大化利用。

### 3.2 系统备电场景（并离网切换）

> **作为** 现场运维工程师，  
> **我希望** 市电中断时系统自动切换至离网模式，由储能供电；当SOC不足时自动启动柴发，切换至柴发供电，  
> **从而** 保障重要负载不间断供电。

**前置条件**：备电阈值设置为 **70%（滞环±1%，即71%停止充电，69%开始充电）**

**验收标准**:
- Grid电压跌落至 < 0.85Un（GB/T 43526-2023 第10章继电保护要求），系统检测到异常
- **≤20ms（1个周波）**内完成并离网切换，基于PCS PLL预同步无缝切换（见下方预同步机制）
- PCS自动从并网(PQ)模式切换至离网(VF)模式（GB/T 34120 并离网切换要求）
- **四层SOC阈值管理**：
  - **柴发启动**：SOC ≤ 20%时发出启动信号（DO-1）
  - **备电恢复**：SOC < 70%时，市电充电恢复备电能力（仅需量约束）
  - **柴发停机**：SOC ≥ 80% 或 市电恢复且ATS切到市电侧
  - **绿电消纳**：SOC ≥ 92%时允许PCS放电做负载跟随
- 柴发启动稳定后（电压/频率正常），ATS切换至柴发侧，STS闭合，PCS并入柴发电压源
- **备电充电策略**（市电恢复场景）：
  - SOC < 69%：市电快充（仅需量约束，快速恢复备电）
  - 71%~90%：只用光伏充电（PCS=0）
  - >90%：光伏充电（需PV功率 > 负载功率）

**异常分支**:
- 柴发启动失败：保持储能供电，告警通知，尝试多次启动（最多3次）
- 柴发停机失败：保持储能供电，告警通知，尝试多次停机，并切除柴发侧断路器（人工操作）
- 柴发燃料不足：告警通知，建议减小负载或等待市电恢复

**设计约束**：储能系统按额定负载持续输出**2小时**设计（符合 GB/T 36274 备用电源配置要求）

#### 预同步无缝切换机制

> **国标关联**：GB/T 36274-2018 第5.2.2条要求微网"计划性/非计划性离网切换"应具备平滑切换能力；本机制通过PCS PLL预同步实现。

**1. 相位连续性原理**

PCS并网时运行在PQ模式（电流源），但内部 **PLL（锁相环）一直在实时跟踪市电相位**：

```
市电相位 θ_grid ──→ PLL跟踪 ──→ PCS内部相位基准 θ_ref = θ_grid

STS切断瞬间：
  θ_ref 保持不变（按市电频率继续积分）
  PCS从 I_ref(PQ) 切换为 V_ref(VF)
  V_ref = 380V∠θ_ref
```

因为 θ_ref ≈ θ_grid，切换瞬间电压向量连续，**无需重新锁相启动**。这是"无感切换"的物理基础。

**2. 20ms 切换时序分解**

| 时间点 | 事件 | 母线状态 |
|--------|------|----------|
| T=0ms | 市电异常，STS收到切断指令，同时通知PCS | 380V 正常 |
| T=5ms | STS动作，市电断开 | 电压开始跌落（PCS仍是电流源） |
| T=8ms | PCS收到STS状态反馈，触发模式切换 | 跌至100~200V |
| T=12ms | PCS从PQ封锁→VF启动，使用锁存相位角 | 开始回升 |
| T=18ms | PCS输出电压恢复至380V | 重建完成 |
| T=20ms | 负载由PCS稳定供电 | **切换完成（1个周波）** |

**3. 负载影响分析**

20ms 断电间隙对各类负载的影响：
- **电机负载**：无感（机械惯性）
- **阻性负载**：无感（热惯性）
- **服务器/PLC**：依赖内部UPS缓冲，20ms通常可接受
- **LED照明**：驱动电容足够，基本无闪烁感知

**4. 为什么不做 LVRT？**

| 策略 | 是否做LVRT | 切换逻辑 |
|------|-----------|----------|
| A. 纯并网型微网 | **必须做** | PCS撑电网，STS晚切或不切 |
| B. 预同步备电型（本项目） | **可以不做** | STS在市电异常时立即切，PCS预同步离网，20ms衔接 |

**本项目采用 STS 快速切换方案**：电网异常时 STS 在电压跌落到 LVRT 触发阈值之前即切断，PCS 不承受故障电压，因此 PCS 无需 LVRT 能力。**注意**：若电网跌落速度过快，STS 切断前 PCS 可能先触发过流或欠压保护而停机。此设计依据 GB/T 43526-2023（380V 用户侧储能）执行，不涉及 GB/T 36547-2024 要求的大型储能电站级故障穿越。

> **国标依据**: GB/T 36274-2018 第5.2条"运行模式控制"要求微网EMS应具备并网/离网/并备用电源模式切换能力；GB/T 33589-2017 第4.2条要求微电网供电可靠性指标。

### 3.3 远程监控场景

> **作为** 云端管理员，  
> **我希望** 通过Web/App查看站点实时状态并下发控制指令，  
> **从而** 实现无人值守站点的远程管理。

**验收标准**:
- 数据刷新延迟 < 5s（4G网络正常时）
- 控制指令下发至执行 < 1s
- 通信中断时本地自主运行，恢复后自动续传断点数据
- 支持远程模式切换（需权限验证）

> **国标依据**: GB/T 42726-2023 第5.4.3条"远方操作"要求支持远程监控、参数修改、控制操作；GB/T 42726 第5.2.5条"数据补传"要求通信恢复后自动补传断点数据。

**业务规则**（GB/T 36274-2018 第5.2.3条"切换控制策略"）：
1. **切换前功率归零**：任何状态切换前，必须先将PCS功率设0，避免电气冲击
2. **同步条件**：并市电/并柴发前，必须检测电压、频率、相序满足同步条件（压差<5%，频差<0.5Hz，相角差<10°）— 符合 GB/T 34120 并离网切换同步要求
3. **VF模式切换**：离网运行时，主PCS转VF（电压源）模式，其他PCS转PQ模式跟随 — 符合 GB/T 34120 第5.2.2条
4. **故障锁定**：进入故障态后，禁止自动切换，需人工确认后恢复（GB/T 42726 第5.4.4条安全操作要求）
5. **扫描周期**：状态机扫描周期100ms，条件持续满足3个周期（300ms防抖）才触发切换 — 符合 GB/T 42726 实时性要求
6. **柴发并网解释**：C4的"并柴发"指STS闭合、ATS切至柴发侧，PCS作为电流源并入柴发电压源，非柴发并网运行
7. **PLL预同步**：并网期间PCS的PLL必须持续跟踪市电相位；离网切换时，PCS直接使用锁存相位角作为VF模式初始相位，无需重新锁相。这是实现≤20ms无缝切换的技术前提（见3.2节预同步机制）。

#### FR-019 PCS簇控制

| 属性 | 描述 |
|------|------|
| **需求描述** | 实现PCS簇的启停控制、功率分配及故障管理，确保簇内多机协调运行 |
| **控制对象** | 簇1 PCS（1#、2#、3#），簇2 PCS（4#、5#） |
| **优先级** | Must |
| **国标依据** | GB/T 34120-2023 第5.2条"并机运行"；GB/T 42726-2023 第5.2.3条"控制调节" |

**PCS主从并机配置**（依据恩玖PCS控制策略文档 4.3.1）：

| 配置项 | 寄存器 | 簇1设置 | 簇2设置 | 说明 |
|--------|--------|---------|---------|------|
| 模块主机设置 | 0x5068 | 1#=1(主机), 2#=0, 3#=0 | 4#=1(主机), 5#=0 | 主机=1，从机=0 |
| 模块电流源并联使能 | 0x5054 | 全部=1 | 全部=1 | 并机场景必须使能 |
| 模块并联台数设置 | 0x5021 | 3 | 2 | 簇1三台并机，簇2两台并机 |

> **配置时机**：EMU上电后与PCS建立通讯后的一次性配置。默认值在设备出厂时已配置可不写入。

**PCS开机顺序（并机场景）**（依据恩玖文档 4.3.2）：
1. 先将所有PCS功率设置为0（0x0D57=0，0x0D58=0）
2. 确认所有PCS停机、非故障（0x6057=0）；若有非硬件故障可尝试0x1400复位一次
3. 先启动**主机PCS**（1#或4#）开关机指令0x0291写1
4. 确认主机PCS启动后（0x605C=3离网运行 或 4并网运行），再**依次启动从机**
5. 从机启动后0x605C将变为4（并网运行）或跟随主机状态

**PCS关机顺序（并机场景）**（依据恩玖文档 4.3.3）：
1. 先将所有PCS功率设置为0（0x0D57写0）
2. 按 **从机→主机** 顺序依次关机：
   - 簇1: 2#→3#→1#（1#主机最后关闭，确保VF模式主站最后退出）
   - 簇2: 5#→4#（4#主机最后关闭）
3. 常规关机：先功率降为0，延时1s后发送关机指令0x0291=0；非常规关机可功率=0同时关机

**PCS功率分配（并机场景）**（依据恩玖文档 4.3.5）：

| 簇 | 主机 | 从机 | 功率控制方式 | 功率边界 |
|----|------|------|--------------|----------|
| **簇1** | 1# | 2#、3# | **仅主机**0x0D57下发总有功功率（0x5054=1使能并联分配），从机自动跟随 | [-375kW, +375kW] |
| **簇2** | 4# | 5# | **仅主机**0x0D57下发总有功功率（0x5054=1使能并联分配），从机自动跟随 | [-250kW, +250kW] |

> **重要**：并机场景下只需给主机PCS的0x0D57写功率值，从机通过0x5054并联使能自动分配功率。禁止单独给从机写功率。

**PCS并离网切换（并机场景）**（依据恩玖文档 4.3.4）：
- **并网转离网**：所有PCS关机→主机0x5066=1(离网)、从机0x5066=0(并网)→先启动主机离网→再启动从机并网→从机0x605C=4
- **离网转并网**：先从机后主机关机→所有PCS 0x5066=0(并网)→启动并网→闭合网侧开关

**PCS故障复位**：
- 并机场景下任一PCS故障需评估对系统影响决定是否全簇停机
- 电池欠压/过压/反接故障恢复后可自动复位，重新并入系统
- 交流主继电器粘连/直流继电器开路/交流主继电器开路：**禁止再次上电**，联系厂家
- 复位前需确认故障已清除，PCS处于停机状态，避免重复触发

#### FR-020 MPPT簇控制

| 属性 | 描述 |
|------|------|
| **需求描述** | 实现MPPT簇的启停控制、功率限制分配，最大化光伏消纳同时保护电池 |
| **控制对象** | 簇1 MPPT（1#、2#、3#、4#），簇2 MPPT（5#、6#、7#） |
| **优先级** | Must |

**MPPT运行模式约束**（关键设计约束）:

| 场景 | 行为特征 | EMS处理要求 |
|------|---------|------------|
| **系统首次上电/MPPT重新上电** | 电压正常后**自动开机** | EMS只需监控确认MPPT已启动，**无需显式发送开机指令** |
| **EMS主动关机后** | 必须显式发送46001=1才能重新开机，不会自动恢复 | EMS关机时必须记录标志位，下次开机**必须先发46001=1** |
| **故障自动恢复后** | 故障清除后**自动重新开机** | EMS只需监控，无需干预 |
| **EMS重启后** | MPPT可能仍在运行（若之前未正常关机） | EMS启动时需读取状态，若已运行则避免重复发送开机指令 |

**MPPT开机顺序**：
1. 先将所有MPPT功率限制设置为0
2. 检查每台MPPT当前运行状态（45200状态字）
3. 若MPPT未运行且需EMS开机：按升序依次发送46001=1开启：**1# → 2# → 3# → 4# → 5# → 6# → 7#**
4. 若MPPT已自动运行：确认通讯正常即可，无需重复开机
5. 每台开启后确认通讯正常，再处理下一台

**MPPT关机顺序**：
1. 先将所有MPPT功率限制设置为0
2. 按降序依次发送46001=0关闭：**7# → 6# → 5# → 4# → 3# → 2# → 1#**
3. 记录`shutdown_by_ems`标志，供下次开机判断使用

**MPPT功率限制控制**：

| 簇 | MPPT设备 | 功率控制方式 | 功率边界 |
|----|----------|--------------|----------|
| **簇1** | 1#、2#、3#、4# | EMS单独控制每台MPPT的46110功率百分比 | [0kW, 400kW] |
| **簇2** | 5#、6#、7# | EMS单独控制每台MPPT的46110功率百分比 | [0kW, 300kW] |

**MPPT功率限制计算**：
- 每簇PV功率限制总值 = 95% × (簇电池总充电需求 - 簇PCS总实时功率)
  - **公式依据**：基于直流侧功率平衡 P_charge_total = P_pv + P_clu（P_clu为负表示PCS从电网充电）
- EMS根据各MPPT实时状态，将总限制值分配给各台MPPT
- 各MPPT功率百分比 = (分配功率 / 基准功率) × 100%

**MPPT故障复位**：
- MPPT支持通过46003寄存器写1清除故障
- 故障自动复位使能(46121)默认开启，故障恢复后可自动重启

**注意事项**：
- MPPT为单向设备（仅充电），功率边界下限为0kW
- 功率限制调整周期 ≤ 4s（MPPT功率限制调节，非PCS功率响应；GB/T 36558 ≤2s 针对PCS功率响应），避免频繁调节导致MPPT抖动
- EMS必须维护每台MPPT的`shutdown_by_ems`状态，确保下次开机逻辑正确

依据 GB/T 42726-2023 第5.3.1条、GB/T 34131-2023 第6.4.1.1条，采用三级报警体系：

| **一级** | GB/T 42726 一级报警 / BMS 三级报警 | 危及人身安全或设备安全，需立即停机或停电处理 | 消防信号、急停触发、**BMS绝缘故障**、STS故障、直流过压、BMS单体过压/欠压/过温/过流、PCS硬件故障（除防雷器/功率模块过温外） |
| **二级** | GB/T 42726 二级报警 / BMS 二级报警 | 影响系统正常运行，需立即采取应急处理措施 | BMS二级告警、PCS母线故障（电池欠压/过压/反接，恢复后可自动复位）、交流主继电器粘连/开路、设备离线（除湿机/关口表） |
| **三级** | GB/T 42726 三级报警 / BMS 一级报警 | 提示性信息，需加强监视及一二级报警复归 | BMS一级告警、门禁（DI8）、滤网堵塞、环境温度过高、SOC偏低预警 |

> **国标依据**: GB/T 42726-2023 第5.3.1条"报警分级"；GB/T 34131-2023 第6.4.1.1条"报警信息分类"。

**一级故障判断内容**：
- **BMS三级告警**：单体电压过高、单体电压过低、充电单体电压压差过高、电池充电温度高/低、充电单体电池温差大、充电过流、放电单体电压压差过高、电池放电温度高/低、放电单体电池温差大、放电过流、电池总压高/低、**电池绝缘阻值低（BMS绝缘检测，PCS不带此功能）**
- **PCS严重故障**：硬件故障字1/2（除防雷器故障、功率模块过温故障外）、电网故障字、交流电容故障字、系统故障字、开关故障字（除交流主继电器粘连、直流继电器开路、交流主继电器开路外）
- **系统级严重故障**：BMS离线、PCS离线、液冷机离线、储能表离线（单PCS场景可省略储能表离线）；DI1急停、DI2浪涌、DI3水浸、DI4消防、DI9PCS故障
- **电能质量严重异常**：关口表/负载表频率畸变、缺相（严重情况）
- **功能节点失效**：关键服务持续超时（数据库、自动下计划曲线、PCS/BMS相关设置）

**一级故障执行**（参考 GB/T 34131-2023 第6.4.3.1条：一级报警发出后300ms内发出停机指令，5s内断开电池簇充放电回路）：
1. 将所有 PCS 功率设置为 0；
2. 控制 PCS 关机；
3. 控制 BMS 高压接触器断开；
4. 点亮故障灯；
5. 若由 DI 输入触发（急停/消防/水浸/浪涌），执行分励脱扣（物理断开）；
6. 故障信息记录日志。

> **注**：顺序下发与执行，不考虑执行结果。设备故障（PCS/BMS 故障）通过软件停机+断开接触器实现；DI 触发的故障额外执行分励脱扣。

**二级故障判断内容**：
- **BMS**：二级告警内容
- **PCS**：母线故障字（电池欠压/过压/反接，故障恢复后可自动复位）；开关故障字中的交流主继电器粘连故障、直流继电器开路故障、交流主继电器开路故障
- **系统**：设备离线（除湿机、关口表）

> **⚠️ 重要**：交流主继电器粘连、直流/交流主继电器开路故障，禁止再次上电，需联系厂家处理。

**二级故障执行**（参考 GB/T 34131-2023 第6.4.3.2条：二级报警发出后300ms内发出降低功率指令）：
1. 将所有 PCS 功率设置为 0，系统处于禁充禁放状态（通过 PCS 功率=0 实现）；
2. 点亮故障灯；
3. 故障信息记录日志。

**三级故障判断内容**：
- **BMS**：一级告警内容
- **DI**：DI8门禁
- **其他**：软件自定义仅告警内容（滤网堵塞、环境温度过高、SOC偏低预警等）

**三级故障执行**：
1. 仅告警，不做动作；
2. 点亮故障灯；
3. 故障信息记录日志。

**故障处理原则**：
1. **一级故障**：立即执行停机序列（PCS功率=0→PCS关机→BMS接触器断开→故障灯→分励脱扣），进入 SysFault 状态，**禁止自动恢复**
2. **二级故障**：执行 PCS 功率=0（禁充禁放），点亮故障灯，**硬件故障禁止自动恢复**，通讯类故障恢复后可尝试自动复位
3. **三级故障**：仅告警和记录，**不触发停机**
4. **故障屏蔽**：并离网切换20ms窗口期及前后防抖共100ms内，屏蔽STS相关无效告警
5. **故障恢复确认**：一级/二级硬件故障恢复后，需本地HMI或远程Web人工点击"确认恢复"，方可从Fault态返回Standby

## 5. 用户侧储能保护需求（GB/T 43526-2023 第5/7/10章）

> **说明**：本项目采用 STS 快速切换方案：电网异常时 STS 在 PCS 进入 LVRT 触发区之前即切断，PCS 无需 LVRT/HVRT 能力。**注意**：若电网跌落速度过快，STS 切断前 PCS 可能先触发过流或欠压保护而停机。因此**不涉及** GB/T 36547-2024（大型储能电站接入电网技术规定）要求的大型储能电站级故障穿越。以下保护需求依据 **GB/T 43526-2023**（用户侧电化学储能系统接入配电网技术规定）。

### 5.1 防逆流保护

| 属性 | 描述 |
|------|------|
| **需求描述** | 防止电能从储能系统倒送电网。当储能系统向电网输出功率时，应自动限制或切断功率输出 |
| **触发条件** | 关口表检测到逆向功率（功率方向为储能→电网） |
| **响应动作** | EMS立即限制PCS放电功率，确保不向电网送电；若限制无效，持续逆流超过设定时间后切换至离网模式 |
| **响应时间** | < 200ms（检测到逆流至功率限制生效） |
| **优先级** | Must |
| **国标依据** | GB/T 43526-2023 第10.7条"采用不允许向电网倒送电方式的用户侧电化学储能系统，公共连接点应具备逆向功率保护功能" |

### 5.2 功率限制（需量保护）

| 属性 | 描述 |
|------|------|
| **需求描述** | 限制储能系统从电网吸收的功率，避免超过用户配电网承载能力 |
| **触发条件** | 关口表功率 > 功率限制阈值（变压器容量的80%或用户设定值） |
| **响应动作** | EMS限制PCS充电功率，使总功率不超过阈值 |
| **响应时间** | < 1s |
| **优先级** | Should |
| **国标依据** | GB/T 43526-2023 第5章"功率控制"（有功功率控制模式配置要求） |

### 5.3 涉网保护定值

| 保护类型 | 动作条件 | 动作时间 | 国标依据 |
|----------|----------|----------|----------|
| 过压保护 | 电压 > 1.10Un | ≤2s | GB/T 43526-2023 第10章继电保护 |
| 欠压保护 | 电压 < 0.85Un | ≤2s | GB/T 43526-2023 第10章继电保护 |
| 过频保护 | 频率 > 50.5Hz | ≤0.2s | GB/T 43526-2023 第7章运行适应性（频率适应性） |
| 欠频保护 | 频率 < 49.5Hz | ≤0.2s | GB/T 43526-2023 第7章运行适应性（频率适应性） |
| 防孤岛保护 | 被动检测（频率/电压越限） | ≤2s | GB/T 43526-2023 第10.6条 |

> **说明**：涉网保护定值需根据缅甸电网实际参数调整。若缅甸电网标称电压/频率与中国不同，需重新核算定值。默认按中国50Hz/380V体系标注。本项目不涉及GB/T 36547-2024要求的大型储能电站级故障穿越。
