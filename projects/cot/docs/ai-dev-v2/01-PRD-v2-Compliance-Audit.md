# 01-PRD-v2 合规性审查报告

> **审查日期**: 2026-04-24  
> **审查对象**: `docs/ai-dev-v2/01-PRD-v2.md`  
> **依据规范**: GB/T 42726-2023、GB/T 36274-2018、GB/T 36558-2023、GB/T 36547-2024、GB/T 43526-2023、GB/T 34120-2023、GB/T 34131-2023  
> **审查结论**: **有条件通过** — 存在1项严重不符合、3项高风险问题、多项一般问题，需修订后复验。

## 一、严重不符合项（Critical）

### ❌ C1: 涉网保护标准适用性错误 — 引用 GB/T 36547 不当

| 项目 | 内容 |
|------|------|
| **问题描述** | 01-PRD-v2 第5章"涉网保护需求"大量引用 GB/T 36547-2024《电化学储能电站接入电网技术规定》，但本项目为用户侧储能系统（工商业微网），应优先适用 **GB/T 43526-2023《用户侧电化学储能系统接入配电网技术规定》**。 |
| **规范依据** | GB/T 43526-2023 第1条明确适用范围："适用于220V及以上接入用户配电网的电化学储能系统"。本项目为缅甸用户侧光储柴微网，属于典型用户侧储能场景。GB/T 36547主要适用于大型储能电站（通常≥10MW或接入高压输电网）。 |
| **风险** | 若按GB/T 36547执行涉网保护，保护定值、测试方法、性能指标可能过于严格，导致：① PCS选型成本上升（需具备高压穿越能力）；② 缅甸电网验收方可能以"标准不适用"为由拒绝；③ 项目交付争议。 |
| **影响范围** | 第5章全部（LVRT/HVRT/涉网保护定值）、6.1节性能指标表"并离网切换时间"行 |
| **修改建议** | ① 涉网保护章节应重新编写，以 GB/T 43526 第6章（功率控制、防逆流、功率限制）为主，GB/T 36547 仅作参考；② 明确标注"本项目为用户侧储能系统，涉网保护要求依据 GB/T 43526-2023"；③ 若缅甸电网有额外要求，单独列出。 |
| **责任方** | 需确认：缅甸电网对储能系统的接入标准是否与GB/T 43526一致，或是否有额外要求。 |

## 二、高风险问题（High Risk）

### ⚠️ H1: 功率方向定义与国标不一致

| 项目 | 内容 |
|------|------|
| **问题描述** | 01-PRD-v2 采用自定义功率方向：`P_pcs正=放电（逆变）`，`P_pcs负=充电（整流）`。但 GB/T 36547-2024 第3.2条和 GB/T 36558-2023 中，储能系统功率方向通常定义为**"充电功率为正"**（从电网吸收功率）或**"向电网送电为正"**。 |
| **规范依据** | GB/T 36547-2024 第3.2条："充电功率"定义为储能系统从电网吸收的有功功率；"放电功率"定义为向电网输送的有功功率。GB/T 36558-2023 第5.2.3条功率控制试验方法中也采用"充电为正"方向。 |
| **风险** | ① 与电网调度/电表的功率方向定义不一致，可能导致计量数据符号相反；② 验收测试时，功率平衡计算可能出现系统性偏差；③ 与第三方云平台对接时数据解释错误。 |
| **影响范围** | 第2.1节功率平衡方程、FR-005/006/008/009 控制目标、第6.1节性能指标 |
| **修改建议** | ① 在"术语表"中增加**"功率方向对照表"**，明确标注"国标定义（GB/T 36547）：充电为正/向电网送电为正" vs "本项目定义：放电为正"；② 所有涉及功率计算/验收的公式，增加方向转换注释；③ 与关口表、电表的功率数据接口处，明确符号处理逻辑。 |

### ⚠️ H2: LVRT/HVRT 实现主体错误

| 项目 | 内容 |
|------|------|
| **问题描述** | 01-PRD-v2 第5.1/5.2节将 LVRT/HVRT 列为EMS需求（LVRT-001/HVRT-001），描述为"PCS应输出无功电流支撑电压恢复"。但**低电压穿越/高电压穿越是PCS级硬件能力**，EMS在LVRT期间的角色是：不下发停机指令、不切换模式、记录事件、配合PCS的无功调节策略。 |
| **规范依据** | GB/T 36547-2024 第6.5/6.6条：LVRT/HVRT 是对**储能变流器（PCS）**的要求，测试方法也是针对PCS单体。EMS（监控系统）在LVRT期间应维持正常运行，不应误判为故障而切除。GB/T 42726-2023 第5.3.1条：EMS应能区分"电网故障"与"设备故障"，避免电网电压跌落时误报警。 |
| **风险** | ① 若恩玖PCS不具备LVRT能力，EMS无法实现该需求，导致Must Have无法交付；② PRD中将PCS能力误写为EMS需求，验收时无法通过；③ EMS在LVRT期间可能误判为"欠压故障"而触发C2保护性停机，反而违反LVRT要求。 |
| **影响范围** | 第5.1节LVRT、第5.2节HVRT、7.1 Must Have优先级表 |
| **修改建议** | ① **删除** LVRT-001/HVRT-001 作为独立FR，改为在FR-008/FR-011中增加"EMS在电网电压异常期间的行为约束"："当电网电压跌落至LVRT范围内时，EMS不得触发C2故障停机，应维持当前并网运行状态，等待PCS自主响应或电网恢复"；② 增加**前提条件**："本需求以PCS具备LVRT/HVRT能力为前提，需在Domain Model中确认恩玖PCS型号的技术规格书"；③ 在EMS故障分级中增加"电网暂态异常"类别（L3-可自动恢复），避免LVRT期间误报L1/L2。 |

### ⚠️ H3: 并离网切换时间与功率响应时间概念混淆

| 项目 | 内容 |
|------|------|
| **问题描述** | 01-PRD-v2 第6.1节性能指标表将"并离网切换时间"标注为"<500ms"，引用 GB/T 36558-2023 第5.2.3条。但 GB/T 36558 第5.2.3条定义的是**"功率控制响应时间"**（PCS收到功率设定到开始响应的时间），不是**STS切换时间**。并离网切换涉及STS机械/电子动作、PCS模式切换、同步判断等多个环节，国标未对"系统级切换时间"做统一规定。 |
| **规范依据** | GB/T 36558-2023 第5.2.3条原文："功率控制响应时间：自功率控制指令下达至功率变化达到目标值90%所需的时间，应不大于500ms。功率调节时间：自功率控制指令下达至功率稳定在目标值±5%范围内所需的时间，应不大于2s。"——这是对PCS功率调节的指标，不是STS切换。GB/T 36274-2018 第5.2.2条提到模式切换，但未规定具体时间限值。 |
| **风险** | ① 验收测试时，若测试方按"并离网切换时间"测试（从市电断开到负载恢复供电），实际时间可能>500ms（受STS动作时间、PCS模式切换时间影响），导致指标不达标；② 混淆概念会让验收标准模糊，产生争议。 |
| **影响范围** | 3.2节验收标准、6.1节性能指标表、FR-008响应时间 |
| **修改建议** | ① **拆分两个指标**：<br>- **功率控制响应时间**（PCS级）：≤500ms（GB/T 36558 第5.2.3条）<br>- **并离网切换时间**（系统级）：待定（取决于STS设备规格，建议标注"需根据STS型号确认，目标<500ms"）；<br>② 3.2节验收标准中，将"500ms内完成STS切换"改为"STS切换动作时间+PCS模式切换时间，目标<500ms（以STS规格书为准）"；<br>③ 明确"功率响应时间"与"切换时间"的测试方法差异。 |

## 三、一般问题（Medium）

### 🔶 M1: 防孤岛保护归属不清

| 项目 | 内容 |
|------|------|
| **问题描述** | 第5.3节涉网保护定值表将"防孤岛保护"列为EMS保护定值，但未明确EMS在防孤岛保护中的角色。防孤岛保护通常由PCS实现（被动检测：频率/电压；主动检测：频率扰动），EMS只是监测PCS的防孤岛动作状态。 |
| **规范依据** | GB/T 36547-2024 第7.6条：防孤岛保护是PCS的保护功能。GB/T 43526-2023 第6.4条：用户侧储能应具备防孤岛保护能力。 |
| **修改建议** | 将"防孤岛保护"从EMS涉网保护定值表中移除，改为在FR-011/FR-021中增加："EMS应监测PCS防孤岛保护动作状态，当PCS因防孤岛保护脱网时，EMS应记录事件并进入离网运行模式，不得误判为故障。" |

### 🔶 M2: 消防联动逻辑缺失

| 项目 | 内容 |
|------|------|
| **问题描述** | 00-Context-v2 中DI×16包含"消防"信号，但01-PRD-v2 缺少消防联动逻辑的FR。GB/T 36558-2023 第5.2.8条和 GB/T 42726-2023 第5.3.1条均要求储能系统具备消防联动能力。 |
| **规范依据** | GB/T 36558-2023 第5.2.8条："储能系统应具备消防联动接口，接收消防信号后应能自动停机并切断电源。"GB/T 42726-2023 第5.3.1条一级报警包含"消防信号"。 |
| **修改建议** | 增加 FR-022 消防联动："当DI-消防信号触发时，系统应立即执行紧急停机：① clearAllPowerSet()；② 断开STS；③ PCS全部停机；④ 记录事件；⑤ 通知云端和本地声光报警。消防信号解除后，需人工确认方可恢复。" |

### 🔶 M3: 绝缘监测未作为独立FR

| 项目 | 内容 |
|------|------|
| **问题描述** | GB/T 34131-2023 第5.4.3条要求BMS具备绝缘监测功能，绝缘电阻低于阈值时应报警。01-PRD-v2 故障码E2xx包含"绝缘故障"，但缺少绝缘监测的独立功能需求。 |
| **修改建议** | 增加 FR-023 绝缘监测："EMS应实时监测BMS上报的绝缘电阻值，当绝缘电阻低于设定阈值（如500Ω/V）时，触发L1-致命告警并执行紧急停机。绝缘监测数据应本地记录并上传云端。" |

### 🔶 M4: 电能质量监测缺失

| 项目 | 内容 |
|------|------|
| **问题描述** | GB/T 43526-2023 第5.4条要求用户侧储能电能质量符合 GB/T 12326（电压波动）、GB/T 14549（谐波）、GB/T 24337（间谐波）等标准。01-PRD-v2 第6.3节"兼容性需求"中列出了电能质量指标限值，但缺少"电能质量监测"作为独立功能需求。 |
| **修改建议** | 增加 FR-024 电能质量监测："EMS应监测并网点电能质量参数（电压偏差、谐波电流、三相不平衡度、电压波动），当指标超过GB/T 43526-2023第5.4条限值时，触发L3告警并记录事件。电能质量数据应支持趋势曲线展示和报表导出。" |

### 🔶 M5: MPPT寄存器地址出现在PRD中

| 项目 | 内容 |
|------|------|
| **问题描述** | FR-020 MPPT簇控制中出现了46001、45200、46110、46003等具体Modbus寄存器地址，以及46121等参数。PRD是产品需求文档，应描述"做什么"而非"怎么做"，底层寄存器地址属于Domain Model或Technical Design的内容。 |
| **修改建议** | 将FR-020中的寄存器地址全部删除，改为描述性需求："EMS应支持对MPPT的启停控制（通过Modbus写寄存器）、功率限制设定（百分比或绝对功率值）、故障清除、运行状态读取。具体寄存器地址和协议格式参见02-Domain-Model-v2。" |

### 🔶 M6: 缺少"计划性离网"触发条件

| 项目 | 内容 |
|------|------|
| **问题描述** | GB/T 36274-2018 第5.2.2条要求微网EMS支持"计划性离网"（人工触发）和"非计划性离网"（故障触发）。01-PRD-v2 的C5条件仅描述了非计划性离网（市电异常），缺少人工触发离网的条件。 |
| **修改建议** | 在状态机流转表中增加："并市电 → 离网：人工离网指令（计划性离网）→ PCS功率设0，同步后离网"；在C5条件中增加"或人工离网指令"。 |

### 🔶 M7: SOC估算精度未提及

| 项目 | 内容 |
|------|------|
| **问题描述** | GB/T 34131-2023 第5.3.2条对SOC估算精度有要求（通常±5%或更高）。01-PRD-v2 所有SOC相关策略（绿电消纳、备电恢复、柴发启动）均依赖SOC值，但未对SOC精度提出要求。 |
| **修改建议** | 在FR-001或新增FR中明确："BMS上报的SOC估算精度应满足 GB/T 34131-2023 要求（±5%），EMS应在Domain Model中记录SOC精度等级，并在SOC接近阈值时适当增加保护余量（精度越差，余量越大）。" |

### 🔶 M8: 变压器额定容量未明确

| 项目 | 内容 |
|------|------|
| **问题描述** | FR-009需量保护提到"变压器容量的80%"，但01-PRD-v2未说明变压器额定容量是多少（如800kVA）。缺少该参数，需量保护的阈值无法计算。 |
| **修改建议** | 在00-Context-v2的设备清单中补充变压器额定容量，或在FR-009中增加参数字段："需量阈值 = 变压器额定容量 × 80%（变压器额定容量：待确认，假设800kVA则阈值为640kW）。" |

### 🔶 M9: IEC 104协议必要性不明

| 项目 | 内容 |
|------|------|
| **问题描述** | 6.3节兼容性需求列出"IEC 104"，但本项目北向为MQTT到私有化云平台，缅甸电网调度是否要求IEC 104接口未知。GB/T 42726支持IEC 104，但非强制。 |
| **修改建议** | 在IEC 104后增加备注："若缅甸电网调度无IEC 104要求，本项降为Won't Have；若需要，需确认调度端接口规格。" |

### 🔶 M10: 遥控返校缺失

| 项目 | 内容 |
|------|------|
| **问题描述** | GB/T 42726-2023 第5.2.4条要求遥控操作应有"返校确认"（选择-返校-执行-确认四步）。01-PRD-v2中FR-004/007等控制需求未明确遥控返校要求。 |
| **修改建议** | 在FR-004手动模式、FR-007柴发联动中增加："遥控操作应支持返校确认机制（选择→返校→执行→确认），确保控制指令可靠执行，防止误操作。" |

## 四、低风险建议（Low / 建议优化）

| 编号 | 问题 | 说明 | 建议 |
|------|------|------|------|
| L1 | 术语"EMU"不常用 | GB/T 42726使用"监控系统"或"能量管理系统"，少用"EMU" | 在术语表中增加："EMU = EMS核心软件模块，部署于WL-EMS-1000-M控制器" |
| L2 | 黑启动说明可更丰富 | Won't Have中仅写"无黑启动能力" | 补充："黑启动需PCS具备VF模式+足够SOC+无外部电源。本项目柴发为冷备份，无法提供黑启动所需的初始电压建立，故不具备。" |
| L3 | 一次调频/惯量响应预留说明 | Could Have中标注"架构预留" | 补充："GB/T 36547要求储能电站具备一次调频/惯量响应，但本项目为用户侧储能（GB/T 43526未要求），架构预留仅为未来扩展。" |
| L4 | 电能计量精度未明确 | GB/T 43526第8章要求电能计量 | 在FR-001或新增FR中明确："关口表精度等级不低于0.5S级，储能表/负载表不低于1.0级" |
| L5 | 数据存储格式未明确 | FR-003提到256GB SSD | 明确存储格式："时序数据库（如InfluxDB/TDengine）+ 结构化事件记录，支持按时间范围快速查询" |
| L6 | 告警分级映射可更清晰 | 四级与国标三级映射已有，但可表格化 | 增加映射表：国标一级→L1，国标二级→L2，国标三级→L3+L4 |
| L7 | MPPT功率限制周期 | "≤4s"与PCS功率调节"≤2s"不一致 | 说明："MPPT功率限制周期4s是避免MPPT频繁调节导致抖动，与PCS功率调节周期2s不冲突" |
| L8 | 柴发启动时序描述模糊 | "总时间受柴发机型、ATS动作时间、STS判断逻辑共同影响" | 建议增加："EMS应可配置柴发启动超时阈值（默认180s），超时后报L2告警" |
