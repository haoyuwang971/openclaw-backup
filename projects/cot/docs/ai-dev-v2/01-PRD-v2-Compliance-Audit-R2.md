# 01-PRD-v2 合规性审查报告（第二轮）

> **审查日期**: 2026-04-24  
> **审查对象**: `docs/ai-dev-v2/01-PRD-v2.md`（GB/T 36547 移除后的版本）  
> **依据规范**: GB/T 42726-2023、GB/T 36274-2018、GB/T 36558-2023、GB/T 43526-2023、GB/T 34120-2023、GB/T 34131-2023  
> **审查结论**: **有条件通过** — 存在1项内部矛盾、1项标准引用存疑、多项数值来源不明，需修订。

---

## 一、内部矛盾（文档自洽性）

### ❌ IC1: 并离网切换时间前后矛盾

| 位置 | 描述 |
|------|------|
| **3.2 备电场景验收标准** | "500ms内完成STS切换至离网，负载电压跌落 < 10%（符合 GB/T 36558 功率响应时间≤500ms）" |
| **3.2 预同步机制** | "≤20ms（1个周波）" |
| **6.1 性能指标** | "≤20ms（1个周波）" |

**问题**：同一节（3.2）中同时出现了 **500ms** 和 **20ms** 两个切换时间指标，互相矛盾。

**分析**：
- 500ms 的来源是上一轮审查前的旧指标，引用的是 GB/T 36558 的"功率响应时间"（PCS收到指令到开始响应的时间），不是系统级切换时间。
- 20ms 是用户确认后的新指标（基于PLL预同步无缝切换）。
- 3.2 验收标准第一行应该改为 20ms，并删除对 GB/T 36558 功率响应时间的错误引用。

**修改建议**：
```
原文：
- 500ms内完成STS切换至离网，负载电压跌落 < 10%（符合 GB/T 36558 功率响应时间≤500ms）

改为：
- ≤20ms（1个周波）内完成并离网切换，负载断电间隙≈20ms，基于PCS PLL预同步无缝切换（见下方预同步机制）
```

## 二、标准引用存疑

### ⚠️ S1: GB/T 43868-2024 未被纳入规范依据

| 位置 | 内容 |
|------|------|
| **1.3 用户画像** | "系统维护人员"行的国标对应写了"GB/T 43868-2024：系统维护要求" |
| **文档头部规范依据** | 未列出 GB/T 43868-2024 |
| **00-Context 标准清单** | 未列出 GB/T 43868-2024 |

**问题**：GB/T 43868-2024（电化学储能电站启动验收规程）只在用户画像中引用了一次，但文档头部的"规范依据"和 00-Context 的标准清单中都没有它。

**分析**：该标准主要适用于储能电站的验收阶段，本项目是用户侧储能微网，且当前阶段是 PRD（需求定义），尚未到验收阶段。在 PRD 中引用该标准意义不大。

**修改建议**：删除 1.3 用户画像中"系统维护人员"行的 GB/T 43868-2024 引用，或将其纳入规范依据并补充到 00-Context。

## 三、数值来源不明（与国标条款对不上）

### 🔶 N1: "Grid电压跌落至 < 0.85Un 持续200ms"

| 位置 | 3.2 备电场景验收标准第一行 |
|------|---------------------------|
| **原文** | "Grid电压跌落至 < 0.85Un 持续200ms，系统检测到异常（GB/T 43526 欠压保护定值）" |
| **问题** | GB/T 43526-2023 第7.2条规定的欠压保护定值是"电压 < 0.85Un，动作时间 ≤2s"，没有"持续200ms"这个条件。200ms 是上一轮审查前从 GB/T 36547 迁移过来的残留。 |

**修改建议**：删除"持续200ms"，改为"Grid电压跌落至 < 0.85Un（GB/T 43526 第7.2条欠压保护定值），系统检测到异常"。

### 🔶 N2: "功率调节周期 ≤ 4s"

| 位置 | FR-005 绿电消纳策略 |
|------|---------------------|
| **原文** | "功率调节周期 ≤ 4s（符合 GB/T 36558 功率调节时间≤2s 的裕度）" |
| **问题** | GB/T 36558-2023 第5.2.3条明确规定"功率调节时间 ≤2s"，文档写 4s 并称之为"裕度"，但标准中没有"裕度"这个概念。如果项目指标是 4s，应明确标注"本项目指标高于国标要求，因...（原因）"。 |

**修改建议**：改为"功率调节周期 ≤ 2s（GB/T 36558-2023 第5.2.3条），本项目预留至 ≤4s 以兼顾MPPT调节稳定性"。

### 🔶 N3: "持续逆流超过60s，触发切换至离网模式"

| 位置 | FR-008 防逆流保护 |
|------|-------------------|
| **原文** | "若实际逆流持续超过60s，触发切换至离网模式保护" |
| **问题** | GB/T 43526-2023 第6.2条要求"防逆流保护响应时间应不大于2s"，但未规定"持续逆流多久后切离网"的阈值。60s 这个数字没有国标依据。 |

**修改建议**：标注"60s 为项目自定义阈值，可根据现场工况调整（GB/T 43526 未规定具体时限）"。

### 🔶 N4: "防逆流余量（5kW）"

| 位置 | FR-008 防逆流保护 |
|------|-------------------|
| **原文** | "关口表功率 > 防逆流余量（5kW），禁止向电网送电" |
| **问题** | GB/T 43526-2023 第6.2条要求"储能系统向电网输送的功率应不大于额定功率的5%或5kW（取较小值）"，不是"禁止向电网送电"。标准允许小功率送出（≤5kW 或 5%），不是绝对禁止。 |

**修改建议**：改为"关口表功率 > 防逆流阈值（5kW，GB/T 43526 第6.2条：向电网输送功率不应超过5kW），EMS限制PCS放电功率使逆向功率 ≤5kW；若限制无效且持续逆流超过设定时间，切换至离网模式"。

## 四、上一轮遗留未修复项

### 🔶 L1: 功率方向与国标不一致（上一轮 H1）

| 位置 | 全文多处 |
|------|----------|
| **问题** | 文档采用自定义功率方向：P_pcs 正 = 放电（逆变），P_pcs 负 = 充电（整流）。但 GB/T 36558-2023 和 GB/T 43526-2023 中，储能系统功率方向通常定义为"充电为正"或"向电网送电为正"。 |
| **风险** | 与电表、调度、验收测试的功率方向定义不一致，可能导致计量数据符号相反。 |
| **状态** | 仍未修复。 |

**修改建议**：在术语表中增加"功率方向对照表"，明确标注国标定义 vs 本项目定义，所有涉及功率计算的公式增加方向转换注释。

### 🔶 L2: 告警抑制时间未更新（上一轮关联问题）

| 位置 | FR-012 告警处理流程 |
|------|---------------------|
| **原文** | "状态切换期间（并离网切换500ms内）抑制无效告警" |
| **问题** | 切换时间已改为 20ms，但告警抑制窗口仍写 500ms。 |

**修改建议**：改为"状态切换期间（并离网切换20ms内及前后防抖窗口共100ms内）抑制无效告警"。

### 🔶 L3: 故障屏蔽窗口未更新（上一轮关联问题）

| 位置 | FR-021 故障处理原则第4条 |
|------|--------------------------|
| **原文** | "并离网切换500ms窗口期内，屏蔽STS相关无效告警" |
| **问题** | 同上，切换时间已改为 20ms。 |

**修改建议**：改为"并离网切换20ms窗口期内及前后防抖窗口共100ms内，屏蔽STS相关无效告警"。

## 五、上一轮遗留的缺失项

### 🔶 M1: 消防联动逻辑缺失（上一轮 M2）

| 位置 | 缺少独立 FR |
|------|-------------|
| **问题** | DI×16 包含"消防"信号（00-Context 已确认），但 01-PRD 缺少消防联动逻辑的 FR。GB/T 36558-2023 第5.2.8条和 GB/T 42726-2023 第5.3.1条均要求储能系统具备消防联动能力。 |
| **状态** | 仍未添加。 |

**修改建议**：增加 FR-022 消防联动："当DI-消防信号触发时，系统应立即执行紧急停机：① clearAllPowerSet()；② 断开STS；③ PCS全部停机；④ 记录事件；⑤ 通知云端和本地声光报警。消防信号解除后，需人工确认方可恢复。"

### 🔶 M2: 绝缘监测缺失（上一轮 M3）

| 位置 | 缺少独立 FR |
|------|-------------|
| **问题** | GB/T 34131-2023 第5.4.3条要求BMS具备绝缘监测功能。故障码 E2xx 包含"绝缘故障"，但缺少绝缘监测的独立功能需求。 |
| **状态** | 仍未添加。 |

**修改建议**：增加 FR-023 绝缘监测。

### 🔶 M3: 电能质量监测缺失（上一轮 M4）

| 位置 | 缺少独立 FR |
|------|-------------|
| **问题** | GB/T 43526-2023 第5.4条要求用户侧储能电能质量符合相关标准。6.3 兼容性需求中列出了限值，但缺少"电能质量监测"作为独立功能需求。 |
| **状态** | 仍未添加。 |

**修改建议**：增加 FR-024 电能质量监测。

### 🔶 M4: MPPT 寄存器地址仍出现在 PRD 中（上一轮 M5）

| 位置 | FR-020 MPPT簇控制 |
|------|-------------------|
| **问题** | 出现了 46001、45200、46110、46003、46121 等具体 Modbus 寄存器地址。PRD 是产品需求文档，应描述"做什么"而非"怎么做"，底层寄存器地址属于 Domain Model 或 Technical Design 的内容。 |
| **状态** | 仍未删除。 |

**修改建议**：将 FR-020 中的寄存器地址全部删除，改为描述性需求："EMS 应支持对 MPPT 的启停控制（通过 Modbus 写寄存器）、功率限制设定（百分比或绝对功率值）、故障清除、运行状态读取。具体寄存器地址和协议格式参见 02-Domain-Model-v2。"

### 🔶 M5: 缺少计划性离网触发条件（上一轮 M6）

| 位置 | 状态机流转表 |
|------|-------------|
| **问题** | GB/T 36274-2018 第5.2.2条要求微网 EMS 支持"计划性离网"（人工触发）和"非计划性离网"（故障触发）。状态机流转表中只有非计划性离网（C5：市电异常），缺少人工触发离网的条件。 |
| **状态** | 仍未添加。 |

**修改建议**：在状态机流转表中增加："并市电 → 离网：人工离网指令（计划性离网）→ PCS功率设0，同步后离网"；在 C5 条件中增加"或人工离网指令"。

### 🔶 M6: 遥控返校缺失（上一轮 M10）

| 位置 | 缺少返校机制描述 |
|------|-----------------|
| **问题** | GB/T 42726-2023 第5.2.4条要求遥控操作应有"返校确认"（选择-返校-执行-确认四步）。FR-004 手动模式、FR-007 柴发联动等控制需求未明确遥控返校要求。 |
| **状态** | 仍未添加。 |

**修改建议**：在 FR-004 和 FR-007 中增加："遥控操作应支持返校确认机制（选择→返校→执行→确认），确保控制指令可靠执行，防止误操作。"
