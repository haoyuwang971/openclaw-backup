## 1. 概述

本文档旨在为能量管理系统（Energy Management System, EMS）软件开发人员提供恩玖PCS(Power Conversion System)设备的详细控制接口说明，确保EMS软件能够正确、高效地控制恩玖PCS设备，实现能量管理策略的精准执行。

- 《【恩玖PCS】通讯协议（通用版本）V1.23.pdf》
- 《20260304开发-恩玖技术交流会议纪要.pdf》

#### 4.1.2 PCS启动控制逻辑

PCS控制器通讯连接后，确认PCS处于停机状态(0x6057为0)。根据表1使PCS设备的相关寄存器按照配置值设置，配置成功后PCS处于配置完成的停机状态。在启动PCS之前需要判断PCS处于：

1. 有功功率、无功功率给定值为0，0x0D57=0，0x0D58=0；
2. 停机、非故障，0x6057=0；
   - (如果检测到PCS处于交流主继电器粘连故障、直流继电器开路故障、交流主继电器开路故障等故障之外的故障)可设置一次故障复位，0x1400写1进行故障清除；
   - 如果持续存在故障则停止启动PCS并触发告警。
3. 检测网侧电压(PCS交流侧处于断开状态接触器的网侧电压)：
   - 若网侧电压存在，设置0x5066=0，PCS并网使能；
   - 若网侧电压不存在，设置PCS离网使能，设置0x5066=1；
   - 若无法检测网侧电压(电气默认并网)，设置PCS并网使能，设置0x5066=0；

满足上述条件之后，给PCS的开关机指令寄存器写1，启动PCS。PCS启动过程0x6057寄存器的值将从0:关机 → 3:开机中 → 5:待机。

- 如果市电存在且市电侧接触器闭合，则并/离网状态寄存器0x605C将从0:停机 → 1:开机中 → 2:待机 → 4:并网运行；
- 如果市电不存在/市电侧接触器处于断开状态，则并/离网状态寄存器0x605C将从0:停机 → 1:开机中 → 2:待机 → 3:离网运行。

#### 4.1.3 PCS关机控制逻辑

**(1) 常规关机流程**：
- 先功率降为0（0x0D57写0），再给关机指令（0x0291写0）；
- 附带延时判定，在下发降功率为0之后1S(可调)功率若未变化，则发送关机指令。

**(2) 非常规关机流程**：
- 功率降为0（0x0D57写0）的同时，下发关机指令（0x0291写0）。

#### 4.1.4 PCS并离网控制逻辑

**(1) 并网转离网控制执行步骤**：

1. 检测到市电缺失，断开市电侧接触器（并网开关），如果有负载开关同时断开负载开关；
2. 给PCS的功率降为0（0x0D57写0）的同时，下发关机指令（0x0291写0）；(执行关机流程)
3. 确认PCS关机后，给0x1400写1进行复位；
   - (如果检测到PCS处于交流主继电器粘连故障、直流继电器开路故障、交流主继电器开路故障)或0x1400写1后持续存在故障则停止PCS转离网过程并触发告警；
4. 确认无故障停机后，给PCS的离网模式设置寄存器0x5066写入1使能PCS离网；
5. 确认PCS离网模式使能后执行PCS开机流程，后PCS寄存器0x605C为3:离网运行；
6. 根据重要负载额定功率大小决定是否闭合负载侧开关(注意过程中保持网侧开关断开)。

**(2) 离网转并网控制**：

1. 检测到市电恢复，断开负载侧接触器（如果存在）；
2. 确认负载开关断开后，执行PCS关机流程；
3. 确认PCS关机后，给0x1400写1进行复位；
   - (如果检测到PCS处于交流主继电器粘连故障、直流继电器开路故障、交流主继电器开路故障)或0x1400写1后持续存在故障则停止PCS转并网过程并触发告警；
4. 确认无故障停机，给PCS的离网模式设置寄存器0x5066写入0使能PCS并网；
5. 确认PCS为并网模式后，闭合网侧开关；
6. 确认网侧开关闭合后，执行PCS启动流程；
7. 确认PCS成功并网运行0x605C为4:并网运行；
8. 闭合负载接触器。

#### 4.1.5 PCS有功功率控制逻辑

当满足以下条件时，可给PCS进行功率设置：

1. PCS处于非故障状态：0x1700~0x1707寄存器为0
2. 并网/离网状态寄存器0x605C处于状态0x4
3. 工作状态寄存器0x6057的bit6为0、bit0与bit8为1

给PCS下发的功率需要满足几个边界条件：

1. PCS的功率设置值在其额定充放电功率范围内，0x0D57当前值域[-125kW, 125kW]；
2. PCS的功率设置频率不能<20ms周期；
3. 根据电池与直流侧其他能源节点功率需求，对PCS的最大充电功率0x5078、最大放电功率0x5079、电池侧最大充电电流限值0x163F、电池侧最大放电电流限值0x1640进行设置。

| 电池侧最大放电电流限值 | 0x1640 | I16 读写，单位A，放大10倍 | 策略给定 | 实时跟随【(BMS给定的最大可放电电流+直流侧光伏注入电流), PCS额定放电电流】 |
| 开机、关机指令 | 0x0291 | I16 读写；写1开机，写0关机 | 策略给定 | 开关机执行前，功率设置为0 |
| 故障复位指令 | 0x1400 | U16（Bit15）第15位；写1进行复位 | 策略给定 | 故障复位指令下发，需要PCS设备处于停机状态 |

#### 4.2.2 PCS启动控制逻辑

PCS控制器通讯连接后，确认PCS处于停机状态(0x6057为0)。根据表1使PCS设备的相关寄存器按照配置值设置，配置成功后PCS处于配置完成的停机状态。在启动PCS之前需要判断PCS处于：

1. 有功功率、无功功率给定值为0，0x0D57=0，0x0D58=0；
2. 停机、非故障，0x6057=0；
   - (如果检测到PCS处于交流主继电器粘连故障、直流继电器开路故障、交流主继电器开路故障等故障之外的故障)可设置一次故障复位，0x1400写1进行故障清除；
   - 如果持续存在故障则停止启动PCS并触发告警。

满足上述条件之后，给PCS的开关机指令寄存器写1（默认设置PCS离网使能，0x5066=1），启动PCS。PCS启动过程0x6057寄存器的值将从0:关机 → 3:开机中 → 5:待机。

并离网的过程由STS判断并执行。

#### 4.2.3 PCS关机控制逻辑

同4.1.3章节。

#### 4.2.4 PCS并离网控制逻辑

PCS与STS组合使用时，并网与离网的判断与动作，由STS执行，并离网状态的判断也根据STS的状态进行判断。

- 离网切换并网的过程较为缓慢，过程中由储能进行带载；
- 并网切换离网的过程为无缝切换，过程时间<20ms，切换后负载立即由PCS直流侧承担。

#### 4.2.5 PCS功率控制逻辑

当满足以下条件时，可给PCS进行功率设置：

1. PCS处于非故障状态：0x1700~0x1707寄存器为0
2. STS的并网/离网状态处于并网状态

给PCS下发的功率需要满足几个边界条件：

1. PCS的功率设置值在其额定充放电功率范围内，0x0D57当前值域[-125kW, 125kW]；
2. PCS的功率设置频率不能<20ms周期；
3. 根据电池与直流侧其他能源节点功率需求，对PCS的最大充电功率0x5078、最大放电功率0x5079、电池侧最大充电电流限值0x163F、电池侧最大放电电流限值0x1640进行设置。

#### 4.3.2 PCS启动控制逻辑

PCS控制器通讯连接后，确认PCS处于停机状态(0x6057为0)。根据表1使PCS设备的相关寄存器按照配置值设置，配置成功后PCS处于配置完成的停机状态。在启动PCS之前需要判断PCS处于：

1. 有功功率、无功功率给定值为0，0x0D57=0，0x0D58=0；
2. 停机、非故障，0x6057=0；
   - (如果检测到PCS处于交流主继电器粘连故障、直流继电器开路故障、交流主继电器开路故障等故障之外的故障)可设置一次故障复位，0x1400写1进行故障清除；
   - 如果持续存在故障则停止启动PCS并触发告警。
3. 检测网侧电压(PCS交流侧处于断开状态接触器的网侧电压)：
   - 若网侧电压存在，设置主机PCS的0x5066=0，让主机PCS并网使能；
   - 若网侧电压不存在，设置主机PCS离网使能，设置0x5066=1；
   - 若无法检测网侧电压(电气默认并网)，设置PCS并网使能，设置0x5066=0；

满足上述条件之后：
- 先给主机PCS的开关机指令寄存器写1，确认主机PCS启动后，再依次启动PCS从机模块；
- 如果市电存在且市电侧接触器闭合，则所有PCS的并/离网状态寄存器0x605C将从0:停机 → 1:开机中 → 2:待机 → 4:并网运行；
- 如果市电不存在/市电侧接触器处于断开状态，则主机PCS的并/离网状态寄存器0x605C将从0:停机 → 1:开机中 → 2:待机 → 3:离网运行。

#### 4.3.3 PCS关机控制逻辑

多台PCS并机场景，先给从机PCS进行关机，再给PCS主机进行关机。

**(1) 常规关机流程**：
- 先功率降为0（0x0D57写0），再给关机指令（0x0291写0）；
- 附带延时判定，在下发降功率为0之后1S(可调)功率若未变化，则发送关机指令。

**(2) 非常规关机流程**：
- 功率降为0（0x0D57写0）的同时，下发关机指令（0x0291写0）。

#### 4.3.4 PCS并离网控制逻辑

**(1) 并网转离网控制执行步骤**：

1. 检测到市电缺失，断开市电侧接触器（并网开关），如果有负载开关同时断开负载开关；
2. 给PCS的功率降为0（0x0D57写0）的同时，下发关机指令（0x0291写0）；(执行关机流程：不分主从先后顺序进行关机)
3. 确认PCS关机后，给0x1400写1进行复位；
   - (如果检测到PCS处于交流主继电器粘连故障、直流继电器开路故障、交流主继电器开路故障)或0x1400写1后持续存在故障则停止PCS转离网过程并触发告警；
4. 确认无故障停机后，给主机PCS的离网模式设置寄存器0x5066写入1使能PCS离网，所有从机PCS的离网模式设置寄存器0x5066写入0使能PCS并网；
5. 确认主机PCS离网模式使能后执行开机流程：先启动主机PCS，待主机PCS寄存器0x605C为3:离网运行后，逐个启动从机PCS，从机PCS寄存器值0x605C将变为4；
6. 根据重要负载额定功率大小决定是否闭合负载侧开关(注意过程中保持网侧开关断开)。

**(2) 离网转并网控制**：

1. 检测到市电恢复，断开负载侧接触器（如果存在）；
2. 确认负载开关断开后，执行PCS关机流程：先将从机PCS逐个执行停机流程，确认从机PCS全部停机完成后，执行主机PCS的关机流程（参考4.1.4）；
3. 确认PCS关机后，给0x1400写1进行复位；
   - (如果检测到PCS处于交流主继电器粘连故障、直流继电器开路故障、交流主继电器开路故障)或0x1400写1后持续存在故障则停止PCS转并网过程并触发告警；
4. 确认无故障停机，给所有PCS的离网模式设置寄存器0x5066写入0使能PCS并网；
5. 确认PCS为并网模式后，闭合网侧开关；
6. 确认网侧开关闭合后，执行PCS启动流程(无指定先后顺序)；
7. 确认所有PCS成功并网运行0x605C为4:并网运行；
8. 闭合负载接触器。

#### 4.3.5 PCS功率控制逻辑

当满足以下条件时，可给PCS进行功率设置：

1. PCS处于非故障状态：0x1700~0x1707寄存器为0
2. 并网/离网状态寄存器0x605C处于状态0x4
3. 工作状态寄存器0x6057的bit6为0、bit0与bit8为1

给PCS下发的功率需要：

1. 给主机PCS的0x0D57寄存器下发整个PCS的充放电有功功率（前提条件：将主、从机的模块电流源并联使能设置寄存器0x5054写1设置为使能，并且根据项目PCS数量配置0x5021并联台数）；
2. 根据电池与直流侧其他能源节点功率需求，对PCS的最大充电功率0x5078、最大放电功率0x5079、电池侧最大充电电流限值0x163F、电池侧最大放电电流限值0x1640进行设置。

> **注**：在组串式、集中式情况下单EMU或多EMU等不同情况使用需要咨询PCS厂家有无特殊处理。

#### 4.3.6 PCS故障处理逻辑

该场景下处理同4.1.6章节，增加的部分为当并机的PCS中任一设备产生故障时，衡量其对系统影响决定是否停机。如产生电池欠压故障、电池过压故障、电池反接故障等故障恢复后，可以自动复位将PCS再并入原系统。
