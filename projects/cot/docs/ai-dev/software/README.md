## 使用指南

### 如果你是系统工程师
先看 [../system/](../system/)，理解系统边界和需求后再看本目录。

### 如果你是软件工程师
1. 从 [01-PRD.md](01-PRD.md) 开始 → 软件需求
2. 读 [03-Architecture.md](03-Architecture.md) → 软件架构
3. 读 [04-State-Machine.md](04-State-Machine.md) → 状态机
4. 读 [11-结构化分析方法.md](11-结构化分析方法.md) 或 [12-面向对象建模方法.md](12-面向对象建模方法.md) → 两种分析视角

### 如果你是项目经理
用 [09-Task-Breakdown.json](09-Task-Breakdown.json) 跟踪开发进度，用 [PENDING-ITEMS.md](PENDING-ITEMS.md) 管理待确认问题。
