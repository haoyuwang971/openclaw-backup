### 2.2 拓扑关键特征

- **两簇PCS交流侧并联**，共接交流母线
- **每簇独立直流母线**：MPPT、电池、PCS直流侧**并联**
- **⚠️ 重要**: MPPT直流输出直接到直流母线，与电池并联（不经过PCS）
- **直流侧功率平衡**: `P_bat = P_pv - P_clu/η`
- **ATS**：市电优先级高，保证单电源输入
- **STS**：并离网切换控制

## 3. 核心功能

### 3.1 能量管理策略

#### 3.1.1 四层SOC阈值管理

| 区间 | SOC范围 | 并网行为 | 离网行为 | 并柴发行为 | 柴发状态 |
|------|---------|----------|----------|------------|----------|
| Zone 4 (绿电) | ≥92% | PCS = 负载×95% | PCS = 负载 | PCS = 0 / 辅助 | 停机 |
| Zone 3 (备电关闭) | 71%~92% | PCS = 0 (待机) | PCS = 负载 | PCS = 0 | 停机 |
| Zone 2 (备电恢复) | 20%~70% | 市电充电 | PCS = 负载×95% | PCS = 0 | 待机 |
| Zone 1 (强制柴发) | <20% | 市电充电 | 柴发强制供电 | PCS = 0 | 必须运行 |

#### 3.1.2 绿电消纳策略

**触发条件**: 两簇最小SOC ≥ 92% 且 并网状态

**控制逻辑**:
- 目标PCS功率 = 负载功率 × 95%（留5%防逆流余量）
- 当PV ≥ 负载：光伏直流直充，PCS放电带载
- 当PV < 负载：PCS放电补充缺口
- 关口表功率 > 5kW（防逆流余量）时限制放电

#### 3.1.3 备电恢复策略

**并网状态**:
- SOC < 70%：市电充电（需量约束，快速恢复备电）
- 71%~90%：只用光伏充电，PCS待机
- >90%：光伏充电（需PV > 负载）

**离网状态**:
- SOC ≥ 92%：PCS满功率放电带载
- 71%~92%：PCS满功率放电带载
- 69%~71%：滞环区，维持当前功率
- <69%：PCS降载5%，准备启动柴发
- ≤20%：强制启动柴发

#### 3.1.4 柴发联动策略

**启动条件** (OR):
- SOC ≤ 20% 且 离网状态
- 远程手动启动

**停机条件** (OR):
- SOC ≥ 80% 且 柴发已稳定运行
- 市电恢复 且 ATS切至市电侧
- 远程手动停机
- 柴发故障

**控制方式**: DO-1硬线启停信号（干接点）

## 4. 故障定义与停机流程

### 4.1 故障分级

| 级别 | 名称 | 恢复方式 | 示例 |
|------|------|----------|------|
| **L1-致命** | 系统级停机故障 | **禁止自动恢复**，必须人工确认后复位 | 直流过压、**BMS绝缘阻值低（PCS不带绝缘检测，绝缘监测由BMS负责）**、急停触发、STS硬件故障 |
| **L2-严重** | 设备级停机故障 | **禁止自动恢复**，人工确认后复位 | PCS通讯中断、BAM通讯中断、PCS过流、BMS过温 |
| **L3-一般** | 功能降级故障 | **可自动恢复**，恢复后自动恢复运行 | MPPT单路故障、液冷机通讯瞬断、电网电压暂降 |
| **L4-提示** | 预警提示 | **无需恢复**，状态消除后自动清除 | 滤网堵塞、环境温度过高、SOC偏低预警 |

### 4.2 故障码分类

| 类别 | 故障码范围 | 说明 |
|------|-----------|------|
| **E0xx** | EMS自身故障 | 通信超时、任务溢出、配置错误、内存不足 |
| **E1xx** | PCS故障 | 过流、过压、欠压、过温、IGBT故障、通讯中断、风扇故障 |
| **E2xx** | BAM/BMS故障 | 单体过压、单体欠压、温差过大、SOC跳变、**BMS绝缘阻值低（PCS不带绝缘检测，绝缘监测由BMS负责）**、通讯中断 |
| **E3xx** | MPPT故障 | 输入过压、输出过压、输出短路、辅源异常、通讯中断、组串不一致 |
| **E4xx** | STS/ATS故障 | STS合闸失败、STS分闸失败、ATS切换超时、STS通讯中断 |
| **E5xx** | 电表故障 | 关口表通讯中断、储能表通讯中断、计量异常 |
| **E6xx** | 柴发故障 | 启动失败、停机失败、油压低、水温高、超速、通讯中断 |
| **E7xx** | 液冷机/环境故障 | 出水高温、出水低温、缺水、通讯中断、环境温度超限 |
| **E8xx** | 系统级保护 | 防逆流触发、需量超限、并离网切换失败、同步失败 |

### 4.3 故障处理原则

1. **L1/L2故障**：立即触发 `clearAllpowerSet()`，进入 SysFault 状态，禁止自动恢复
2. **L3故障**：记录告警，尝试降功率或切换模式运行，通信恢复后自动恢复
3. **L4故障**：仅记录日志和提示，不触发停机
4. **故障屏蔽**：并离网切换500ms窗口期内，屏蔽STS相关无效告警
5. **故障恢复确认**：L1/L2故障恢复后，需本地HMI或远程Web人工点击"确认恢复"，方可从Fault态返回Standby

### 4.4 正常停机流程

**执行顺序**（严格按步骤，每步确认后才进行下一步）：

| 步骤 | 动作 | 超时处理 |
|------|------|----------|
| 1 | 停止策略计算，状态机进入停机子流程 | - |
| 2 | clearAllpowerSet()：所有PCS功率设为0，等待实际功率<5kW | 5s超时转故障停机 |
| 3 | 所有MPPT功率百分比设为0，等待输出侧功率归零 | 10s超时转故障停机 |
| 4 | 柴发停机（DO-1断开），等待转速归零 | 120s超时转故障停机 |
| 5 | 确认STS已分闸 | 3s超时转故障停机 |
| 6 | PCS关机序列：2#→3#→4#→5#→1#（主机最后关），每台间隔≥2s | 单台5s超时上报 |
| 7 | 保存停机前运行数据快照，记录停机日志 | - |
| 8 | 确认所有设备待机，系统回到SysStandby，显示"可安全断电" | - |

### 4.5 故障停机流程

**与正常停机的核心区别**：故障停机是紧急保护，不等待设备响应，以最快速度进入安全状态，必须人工确认才能恢复。

**执行顺序**（按优先级，可并行）：

| 优先级 | 步骤 | 动作 | 时限 |
|--------|------|------|------|
| P0 | 1 | 紧急功率清零：所有PCS功率=0，所有MPPT限功率=0 | <100ms |
| P1 | 2 | 柴发停机信号（DO-1断开），不等待实际停机 | 500ms |
| P1 | 3 | 故障分级判定（L1/L2进入Fault态锁定，L3仅记录） | 500ms |
| P2 | 4 | 状态机切换至SysFault，冻结状态，禁止自动转换 | 2s |
| P2 | 5 | 本地声光告警+云端MQTT推送+屏幕弹窗 | 2s |
| P3 | 6 | 保存故障前1秒运行数据快照，写保护关键区域 | 5s |
| P3 | 7 | 持续监测设备状态，记录"设备停机异常"次级故障 | 持续 |

**故障恢复流程**：运维排除故障源 → 本地HMI/Web点击"故障恢复确认" → EMS验证AllNoFault → 状态机SysFault→SysStandby → 等待开机指令。

## 5. 状态机设计

### 5.1 系统状态定义

| 状态ID | 状态名称 | PCS模式 | EMS功率控制 | 说明 |
|--------|----------|---------|-------------|------|
| S0 | SysStandby (待机) | 待机 | 否 | 系统初始化/等待 |
| S1 | SysOffGrid (离网) | VF模式 | 否 | PCS自主均流带载 |
| S2 | SysCnetGrid (并市电) | PQ模式 | 是 | EMS直接控制功率 |
| S3 | SysCnetGent (并柴发) | PQ模式 | 否 | 柴发主导，PCS待机 |
| S4 | SysFault (故障) | 停机 | 否 | 保护性停机 |

### 5.2 状态转换条件

| 条件 | 名称 | 详细定义 |
|------|------|----------|
| **C1** | 开机就绪 | 所有设备通讯正常 ∧ 无故障 ∧ PCS开机 ∧ 配置正常 ∧ 电压正常 |
| **C2** | 故障条件 | 任一设备通讯故障 ∨ 设备故障 ∨ 系统功能节点故障 |
| **C3** | 并市电条件 | 通讯正常 ∧ 无故障 ∧ ATS市电IO=1 ∧ STS并网状态=1 ∧ 市电电压正常 |
| **C4** | 并柴发条件 | 通讯正常 ∧ 无故障 ∧ ATS市电IO=0 ∧ 备用IO=1 ∧ STS并网状态=1 ∧ 柴发电压正常 |
| **C5** | 切离网条件 | 通讯正常 ∧ 无故障 ∧ STS并网状态=0 ∧ 市电/柴发异常 |
| **C6** | 转待机条件 | 通讯正常 ∧ 无故障 ∧ PCS关机 ∧ 电压正常 |

### 5.3 状态流转矩阵

| 当前状态 | 条件 | 目标状态 | 动作 |
|----------|------|----------|------|
| 待机 | C1 | 离网 | powerOnAllPCS() |
| 待机 | C2 | 故障 | clearAllpowerSet() |
| 离网 | C3 | 并市电 | clearAllpowerSet() |
| 离网 | C4 | 并柴发 | clearAllpowerSet() |
| 离网 | C2 | 故障 | clearAllpowerSet() |
| 并市电 | C5 | 离网 | clearAllpowerSet() |
| 并市电 | C2 | 故障 | clearAllpowerSet() |
| 并柴发 | C5 | 离网 | clearAllpowerSet() |
| 并柴发 | C2 | 故障 | clearAllpowerSet() |
| 故障 | C6+人工 | 待机 | 故障清除确认 |

**防抖机制**: 条件持续满足3个扫描周期(300ms)才触发

### 5.4 状态机扫描周期

- **扫描周期**: 100ms
- **防抖周期**: 3个周期 (300ms)
- **同步压差阈值**: <5%
- **同步频差阈值**: <0.5Hz
- **同步相角阈值**: <10°

### 6.2 MPPT (吉瓦时代 V2.5.0.0) - RS485

**通信参数**: Modbus-RTU, 9600bps, 8N1

#### 核心遥测寄存器

| 地址 | 名称 | 类型 | 单位 | 增益 | 说明 |
|------|------|------|-----|------|------|
| 45200 | 状态字 | U16 | - | - | Bit8=允许启机 |
| 45217 | 输入侧总功率 | U16 | kW | ×10 | PV输入功率 |
| 45218 | 输出侧总功率 | U16 | kW | ×10 | 直流输出 |
| 45219 | 输入侧电压 | U16 | V | ×10 | PV电压 |

#### 控制寄存器

| 地址 | 名称 | 类型 | 增益 | 范围 | 说明 |
|------|------|------|------|------|------|
| 46001 | 开机 | U16 | - | 0/1 | 0=关机，1=开机 |
| 46003 | 故障清除 | U16 | - | 0/1 | 写1清除故障 |

| 46121 | 故障自动复位使能 | I16 | - | 0/1 | 默认1=使能 |

**⚠️ MPPT控制要点**:
- EMS直接对每台MPPT独立设置功率百分比，不再通过主机分配
- 自动运行模式下电压正常后自动开机
- EMS主动关机后必须显式发送46001=1才能重新开机

### 6.3 BAM (高特 ESMU V2.1) - Modbus TCP

**通信参数**: LAN1(簇1)/LAN2(簇2), 端口502, 单元标识符1

#### 核心输入寄存器

| 地址 | 名称 | 类型 | 单位 | 倍率 | 说明 |
|------|------|------|-----|------|------|
| 2 | 电池堆电压 | U16 | V | ×10 | - |
| 3 | 电池堆电流 | I16 | A | ×10 | 偏移-1600A，充电为正 |
| 4 | 电池堆SOC | U16 | % | ×1 | **EMS核心控制参数** |
| 32 | 允许最大放电功率 | U16 | kW | ×10 | BMS功率边界 |
| 33 | 允许最大充电功率 | U16 | kW | ×10 | BMS功率边界 |
| 43 | BMS堆当前状态 | U16 | - | - | 0=初始化,1=充电,2=放电,3=就绪... |
| 47 | EMS通信故障 | U16 | - | - | 0=正常，1=故障 |

#### 控制保持寄存器

| 地址 | 名称 | 类型 | 说明 |
|------|------|------|------|
| 500 | 电池组数 | U16 | 簇数量 |
| 501 | 系统故障复位 | U16 | 写1复位 |
| 503 | 系统上下电 | U16 | 0=掉电，1=上电，2=复位 |
| **530** | **心跳** | U16 | **EMS需定期写入** |

**⚠️ 重要**: EMS必须定期向地址530写入心跳，否则BAM报EMS通信故障

## 7. 系统架构

### 7.1 分层架构

| 层级 | 名称 | 职责 |
|------|------|------|
| L1 | 交互层 | 用户界面、远程监控、告警通知 |
| L2 | 应用层 | 能量管理策略、模式控制、功率分配 |
| L3 | 状态层 | 系统状态机、状态流转、安全防护 |
| L4 | 服务层 | 设备通信、数据存储、事件记录 |
| L5 | 设备层 | PCS/MPPT/BAM/STS等物理设备 |

### 7.2 关键性能指标

| 指标 | 要求 | 说明 |
|------|------|------|
| **并离网切换时间** | < 500ms | 从Grid异常检测到负载切换完成 |
| **防逆流响应时间** | < 200ms | 检测到逆流至功率限制生效 |
| **柴发启动延迟** | < 10s | 从DO-1闭合到柴发开始启动 |
| **数据刷新延迟** | 本地< 1s，云端< 5s | 正常网络条件下 |
| **状态机扫描周期** | 100ms | 条件检测和状态判断周期 |

### 7.3 数据采集周期

| 设备 | 采集周期 | 说明 |
|------|----------|------|
| PCS (RS485-1/2) | 每3秒轮询 | - |
| MPPT (RS485-5/6) | 每3秒轮询，分别写7台功率百分比 | - |
| BAM (TCP) | 每1秒读取，写心跳(地址530) | - |
| STS (RS485-3) | 每100ms读取（状态机用） | - |
| 电表 (RS485-4) | 每200ms读取（防逆流用） | - |
| 液冷机 (RS485-7) | 每5秒轮询 | 监控出水/回水温度 |
