## 2. TC-1 南向设备数据采集与控制

> **原则**：数采测试不分运行模式（并网/离网/并柴发均可）。控制测试**先走手动模式**，验证EMS能正确下发指令到各设备。

### 1.1 设备通信接入

#### TC-1.01 全部23台设备在线识别

| 属性 | 内容 |
|------|------|
| **关联需求** | FR-001, SR-011 |
| **前置条件** | EMS控制器已上电；全部23台设备已正确接线并供电；无急停信号 |
| **测试步骤** | 1. HMI进入"设备状态"页面<br>2. 查看设备列表，统计在线数量<br>3. 逐一核对设备名称、类型、地址、通信接口 |
| **预期结果** | 1. 23台设备全部显示"在线"<br>2. 设备列表与02-Domain-Model地址分配表一致（RS485-1~7、LAN1~2、DO/DI）<br>3. 无红色通信告警 |
| **验收标准** | 在线率=100%；识别时间≤60s |
| **测试工具** | HMI |
| **优先级** | Must |

#### TC-1.02 PCS数据采集正确性

| 属性 | 内容 |
|------|------|
| **关联需求** | FR-001 |
| **前置条件** | 5台PCS均在线；并网或离网运行均可；HMI显示PCS数据页面 |
| **测试步骤** | 1. 记录HMI显示的各PCS交流有功功率、直流电压、直流电流、状态字、运行模式<br>2. 使用Modbus工具直接读取PCS寄存器（对照02-Domain-Model地址表）<br>3. 对比HMI显示值与Modbus原始值 |
| **预期结果** | 1. HMI显示值 = Modbus原始值 × 倍率（对照02-Domain-Model寄存器表）<br>2. 功率方向正确（PCS放电为正，充电为负）<br>3. 状态字、故障字解析正确 |
| **验收标准** | 数值误差≤0.5%；方向正确率100% |
| **测试工具** | Modbus Poll、HMI |
| **优先级** | Must |

### 1.2 手动模式设备控制

> **前提**：系统处于**手动模式**，待机或离网/并网运行均可。

#### TC-1.09 手动模式下PCS功率设定

| 属性 | 内容 |
|------|------|
| **关联需求** | FR-004 |
| **前置条件** | 手动模式；并网运行；PCS全部在线；无故障 |
| **测试步骤** | 1. HMI进入"手动控制"页面<br>2. 设定簇1 PCS功率 = +50kW（放电）<br>3. 设定簇2 PCS功率 = -30kW（充电）<br>4. 观察PCS实际功率响应<br>5. 将功率设回0 |
| **预期结果** | 1. PCS在4s内响应功率设定<br>2. 实际功率与设定值误差≤±5kW<br>3. 功率归零时PCS待机 |
| **验收标准** | 响应时间≤4s；功率误差≤±5kW |
| **测试工具** | HMI、功率分析仪 |
| **优先级** | Must |

#### TC-1.10 手动模式下PCS模式切换（PQ↔VF）

| **验收标准** | 模式正确；电压/频率达标；切换时间≤2s |
| **测试工具** | HMI、示波器 |
| **优先级** | Must |
