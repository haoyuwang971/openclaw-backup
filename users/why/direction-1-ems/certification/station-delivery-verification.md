# 电站交付验证指南

> **范围**：针对整个储能电站（含 EMS、PCS、BMS、电池、变压器、消防等）在项目现场安装完成后、并网投运前的系统级验证。  
> **目的**：确保整站满足安全、性能、并网要求，获得投运许可。  
> **与产品认证的区别**：产品认证是 EMS 出厂前的"体检报告"；电站验证是项目现场的"毕业考试"。

---

## 一、国内：储能电站交付验证

### 1.1 验证阶段总览

```
阶段一：到货验收
    ├─ 设备开箱检查
    ├─ 资料核查（型式试验报告、合格证、说明书）
    └─ 外观及数量确认

阶段二：安装调试
    ├─ 单体设备调试（PCS、BMS、EMS 分别上电）
    ├─ 分系统联调（EMS↔PCS、EMS↔BMS、EMS↔调度）
    ├─ 消防系统联调
    └─ 保护定值整定

阶段三：并网检测（第三方）
    ├─ 电能质量测试
    ├─ 功率控制测试
    ├─ 电网适应性测试
    ├─ 保护功能测试
    └─ 高低压穿越测试

阶段四：试运行
    ├─ 72h / 168h 连续试运行
    ├─ 运行数据记录
    └─ 故障模拟与恢复

阶段五：启动验收
    ├─ 电网公司并网许可
    ├─ 消防验收
    ├─ 质监站质量监督检查
    └─ 竣工验收
```

### 1.2 并网检测核心项目

依据 **GB/T 36547-2024**《电化学储能电站接入电网技术规定》：

| 检测项目 | 技术要求 | 备注 |
|----------|----------|------|
| **功率控制响应** | 收到指令 ≤500ms 响应，≤2s 达目标值 90% | EMS 核心能力 |
| **一次调频** | 死区 ±(0.03~0.05)Hz，下垂 3%~5% | 电网侧/共享储能必做 |
| **惯量响应** | 模拟同步机惯量，响应时间 ≤1s | 构网型项目关注 |
| **高电压穿越** | 1.15~1.20pu 不脱网运行 | PCS 能力，EMS 协调模式切换 |
| **低电压穿越** | 0~0.90pu 电压跌落不脱网 | PCS 能力，EMS 协调模式切换 |
| **连续故障穿越** | 多次故障序列下保持并网 | 2024 版新增要求 |
| **频率适应性** | 47.5~50.5Hz 正常运行 | EMS 频率保护阈值需配合 |
| **电能质量** | 谐波、闪变、三相不平衡满足 GB/T 12325/14549 | 全站测试 |
| **充放电转换时间** | ≤400ms（响应调度） | EMS+PCS 联合指标 |
| **并网冲击电流** | ≤1.5 倍额定电流 | 软启动控制 |

### 1.3 启动验收（GB/T 43868-2024）

依据 **GB/T 43868-2024**《电化学储能电站启动验收规程》：

```
启动验收必备条件：
├─ 设备资料齐全（型式试验报告、出厂试验报告、合格证）
├─ 安装调试完成并通过自检
├─ 并网检测报告合格
├─ 保护定值经电网公司确认
├─ 消防系统通过专项验收
├─ 环保、水保手续完备（大型电站）
├─ 运行规程、应急预案编制完成
├─ 运维人员培训合格
└─ 试运行期间故障已处理完毕
```

### 1.4 验收参与方

| 参与方 | 职责 | 关注重点 |
|--------|------|----------|
| **电网公司** | 并网许可、调度协议签订 | 涉网性能、通信规约、保护配合 |
| **第三方检测机构** | 并网检测、出具报告 | 客观测试结果 |
| **消防部门** | 消防专项验收 | 消防系统有效性、逃生通道 |
| **质监站** | 工程质量监督 | 施工质量、设备安装规范 |
| **业主/投资方** | 竣工验收、接收 | 功能完整性、性能达标 |
| **EPC 总包** | 组织验收、问题整改 | 整体协调、资料汇总 |

## 二、国外：储能电站交付验证

### 2.1 欧洲

#### 并网测试（以德国为例）

| 测试项 | 依据标准 | 说明 |
|--------|----------|------|
| **VDE-ARN 4105** | 低压并网（≤30kW） | 反孤岛、功率控制、电能质量 |
| **VDE-ARN 4110** | 中压并网（>30kW） | 更严格的故障穿越、频率响应 |
| **VDE-ARN 4120** | 高压并网 | 需电网公司深度参与测试方案 |
| **CEI-016** | 意大利并网 | 类似德国但有自己的特殊要求 |

#### 通用测试要求

| 类别 | 测试内容 | 标准 |
|------|----------|------|
| **电气安全** | 绝缘、接地、漏电流 | IEC 62477-1 |
| **EMC** | 传导骚扰、辐射骚扰、抗扰度 | IEC 61000-6-x 系列 |
| **环境** | 温升、防护等级（IP）、盐雾 | IEC 60529、IEC 60068 |
| **网络安全** | 渗透测试、漏洞扫描 | IEC 62443-3-3 |
| **功能安全** | 安全功能验证（若适用） | IEC 61508 / ISO 13849 |

### 2.2 北美

#### IEEE 1547 / 1547.1 并网测试

| 测试类别 | 具体内容 |
|----------|----------|
| **反孤岛测试** | 主动/被动防孤岛保护验证 |
| **电压调节** | 无功功率-电压支撑能力 |
| **频率响应** | 过频/欠频保护及频率-有功响应 |
| **低电压穿越** | 电压跌落期间不脱网运行 |
| **高电压穿越** | 电压升高期间不脱网运行 |
| **电能质量** | 谐波、闪变、直流注入 |
| **启动特性** | 并网冲击电流、软启动 |
| **通信** | IEEE 2030.5（智能逆变器通信协议） |

#### 地方电网公司特殊要求

| 电网公司 | 特殊要求 |
|----------|----------|
| **加州 CAISO** | Rule 21 附加测试 |
| **德州 ERCOT** | 快速频率响应（FFR） |
| **夏威夷 HECO** | 更严格的电压/频率范围 |

### 2.3 澳洲

| 测试项 | 依据标准 | 说明 |
|--------|----------|------|
| **AS/NZS 4777.2** | 分布式发电并网 | 反孤岛、电压/频率保护 |
| **AS 61000.3.6** | 谐波限制 | 中压系统谐波评估 |
| **ENA 申请** | 电网接入申请 | 需提前向当地 DNSP 提交 |

### 2.4 日本

| 功率等级 | 依据标准 | 说明 |
|----------|----------|------|
| **<50kW** | JIS C 4412-1/2 | 低压并网，测试相对简单 |
| **>50kW** | JEAC 9701 | 中高压并网，需电力公司参与 |
| **全等级** | JIS C 4411-2 | EMC 要求 |

## 三、国内外电站验证对比

| 维度 | 国内 | 国外（欧美为主） |
|------|------|-----------------|
| **核心并网标准** | GB/T 36547-2024 | IEEE 1547 / EN 50549 / VDE |
| **检测机构** | 电网指定机构（中国电科院等） | 独立第三方 + 电网公司联合 |
| **网络安全** | 等保 2.0（推荐） | IEC 62443（强制趋势） |
| **故障穿越** | 2024 版新增连续穿越 | 要求更严格（多级跌落） |
| **仿真模型** | 部分项目要求 | 大规模项目强制要求 |
| **验收主导方** | 质监站 + 电网 | 电网公司主导 |
| **试运行时长** | 72h / 168h | 通常 168h 或更长 |
| **消防验收** | 国内强制且严格 | 各国差异大（NFPA 855 美国） |

## 四、Cot 项目（光储柴微网）特殊验证

Cot 是多模式微网，电站验证时需额外关注：

### 4.1 多模式切换验证

| 切换场景 | 验证内容 | 合格标准 |
|----------|----------|----------|
| **并网 → 离网** | 电网失电检测、切换逻辑、负载不间断供电 | 切换时间 ≤20ms（若涉 STS）或 ≤2s |
| **离网 → 并网** | 同期检测、相位/频率/电压差满足条件后合闸 | 同期差 ≤5% |
| **离网 → 并柴发** | 柴发启动指令、VF 控制权移交、负载转移 | 柴发启动至带载 ≤30s（冷备） |
| **并柴发 → 并网** | 柴发停机、平滑切回电网 | 无冲击 |

### 4.2 柴发专项验证

```
□ 柴发自动启动逻辑（SOC 阈值触发）
□ 柴发与 PCS 的 VF 协调控制
□ 柴发 overload / underload 保护
□ 柴发燃料液位监控与报警
□ 柴发运行时间累计与维护提醒
□ 柴发退出时的负载转移验证
```

### 4.3 防逆流验证（若涉及）

```
□ 功率流向监测精度（≤1% 额定功率）
□ 逆流保护动作时间（≤2s）
□ 防逆流与负载跟踪的协调
□ 多台 PCS 并联时的防逆流一致性
```

### 4.4 需量控制验证（若涉及）

```
□ 需量测量精度
□ 需量超限预警与自动减载
□ 多时段需量策略执行
□ 历史需量数据记录与报表
```

## 六、常见问题与建议

### 6.1 EMS 产品认证 vs 电站验证的衔接

| 场景 | 处理方式 |
|------|----------|
| EMS 已有检验报告，换项目投运 | 直接用于资格审查，现场只做联调和并网检测 |
| EMS 全新产品，首次投运 | 先送检取得报告 → 投标 → 中标后现场联调 → 并网检测 |
| EMS 软件升级，已投运项目 | 评估是否涉及安全功能变更 → 必要时补充测试 → 更新报告 |

### 6.2 时间规划建议

| 阶段 | 建议时长 | 备注 |
|------|----------|------|
| EMS 产品送检 | 4~8 周 | 含排队时间 |
| 现场安装调试 | 2~4 周 | 视项目规模 |
| 并网检测 | 2~3 周 | 需提前预约检测机构 |
| 试运行 | 7~14 天 | 72h 或 168h |
| 验收流程 | 2~4 周 | 多部门并联推进 |

**关键路径**：EMS 产品送检是前置条件，建议**至少提前 2 个月**启动。

### 6.3 费用预估（参考）

| 项目 | 国内 | 国外 |
|------|------|------|
| EMS 第三方检验报告 | 5~15 万元 | 2~5 万欧元（CE+IEC） |
| 全站并网检测 | 20~50 万元 | 5~15 万欧元 |
| IEC 62443-3-3 SL2 | — | 3~8 万欧元 |
| 电网公司验收费用 | 按容量计费 | 按项目协商 |
