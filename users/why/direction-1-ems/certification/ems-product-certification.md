# EMS 产品认证指南

> **范围**：仅针对 EMS（能量管理系统）控制器本身，作为独立产品形态的认证要求。  
> **目的**：产品出厂、投标入围、市场准入。  
> **与电站验证的区别**：产品认证是"卖 EMS 之前"的事；电站验证是"项目投运之前"的事。

---

## 一、国内：EMS 产品认证

### 1.1 核心认证：第三方检验报告

| 项目 | 要求 |
|------|------|
| **依据标准** | GB/T 42726-2023《电化学储能电站监控系统技术规范》 |
| **机构资质** | 必须同时具有 **CMA**（中国计量认证）+ **CNAS**（中国合格评定国家认可委员会）资质 |
| **报告类型** | 型式试验报告 / 检验报告 |
| **适用范围** | 电化学储能电站用 EMS（含 SCADA、控制调节、报警、通信、HMI 等） |

#### 检测机构清单

| 机构 | 特点 | 适用场景 |
|------|------|----------|
| 中国电科院 | 最权威，电网认可度高 | 大型电站项目、电网侧储能 |
| 各省电科院（广东/江苏/浙江等） | 属地服务快，熟悉当地电网要求 | 属地项目、工商业储能 |
| TÜV 莱茵（中国） | 国际+国内双资质 | 有出海计划，想一测多用 |
| SGS 通标 | 国际网络广 | 出口转内销或外企项目 |
| 鉴衡认证（CGC） | 新能源领域专精 | 风光储项目经验丰富 |
| 中国质量认证中心（CQC） | 国字号背书 | 强制或半强制认证场景 |

#### 检验内容（基于 GB/T 42726-2023）

```
├─ 功能测试
│  ├─ 数据采集与监视（SCADA）
│  ├─ 控制调节（有功/无功功率、电压调节）
│  ├─ 报警分级与处理
│  ├─ 事件顺序记录（SOE）
│  └─ 人机界面（HMI）
│
├─ 性能测试
│  ├─ 响应时间（遥信变位 ≤2s，遥控响应 ≤1s）
│  ├─ 数据精度（模拟量误差 ≤0.2% 或 ≤0.5%）
│  ├─ 系统可用率（≥99.9%）
│  └─ 冗余切换时间（双机热备 ≤10s）
│
├─ 通信测试
│  ├─ 与 PCS 通信（Modbus/104/61850）
│  ├─ 与 BMS 通信（CAN/以太网）
│  ├─ 与调度主站通信（104/61850）
│  └─ 通信中断容错
│
├─ 环境测试
│  ├─ 工作温度（-10℃~+55℃ 或工业级 -20℃~+60℃）
│  ├─ 湿热、盐雾（若用于沿海或户外）
│  └─ 电磁兼容（EMC）
│
└─ 安全测试
   ├─ 绝缘电阻
   ├─ 介电强度
   └─ 工控信息安全（可选，但越来越重要）
```

> ⚠️ **关键提示**：近期大型储能项目招标（中国能建 25GWh、四川安岳 100MW/200MWh 等）已明确将 EMS 检验报告列为核心设备资格审查项，与 PCS 型式试验报告、BMS 型式试验报告并列。**没有报告 = 投标资格都没有**。

### 1.2 补充认证（视项目要求）

| 认证类型 | 适用标准/要求 | 触发条件 |
|----------|---------------|----------|
| **软件著作权** | 《计算机软件保护条例》 | 软件自主研发，投标加分项 |
| **信创/国产化适配** | T/CIAPS 0051-2025 等团标 | 涉国企、政府、电网侧项目 |
| **等保测评** | 等保 2.0（三级或以上） | 接入调度系统、涉网运行的 EMS |
| **工控安全认证** | IEC 62443-3-3 SL2（国内版） | 关键信息基础设施项目 |
| **消防联动认证** | 与消防系统联调报告 | 消防验收强关联项目 |

## 二、国外：EMS 产品认证

### 2.1 欧洲市场

| 认证/标准 | 强制/推荐 | 作用 | 认证机构 |
|-----------|-----------|------|----------|
| **CE Mark** | 强制 | 欧盟市场准入基本条件 | 欧盟公告机构（Notified Body） |
| **IEC 62443-3-3 SL2** | 越来越强制 | 工业网络安全认证，欧洲大储项目已从"加分项"变为"必选项" | TÜV/BV/SGS/DEKRA |
| **IEC 61850** | 强制 | 变电站通信协议，电网调度系统互联互通 | 各认可实验室 |
| **IEC 62351** | 推荐 | 电力系统数据通信安全 | 各认可实验室 |
| **EN 50549-1** | 强制 | 低压分布式发电并网要求 | 各国电网认可机构 |
| **EN 50549-2** | 强制 | 中压分布式发电并网要求 | 各国电网认可机构 |
| **VDE-ARN 4105/4110/4120** | 强制（德国） | 德国并网规程，测试严格 | VDE/ TÜV |
| **RoHS** | 强制 | 有害物质限制 | 第三方检测机构 |
| **REACH** | 强制 | 化学品注册、评估、授权 | 第三方检测机构 |

> 🔥 **重点**：IEC 62443-3-3 SL2 是 EMS 出海的"网络安全护照"。TCC 储能 2026 年 3 月通过 BV 认证后明确用于欧洲投标。这个认证的难点在于**系统级**评估（身份验证、访问控制、数据加密、异常事件响应），不是单一硬件过 EMC。

### 2.2 北美市场

| 认证/标准 | 强制/推荐 | 作用 | 认证机构 |
|-----------|-----------|------|----------|
| **UL 1741** | 强制 | 分布式发电并网安全标准 | UL/CSA |
| **IEEE 1547 / 1547.1** | 强制 | 并网及反孤岛测试 | IEEE 认可实验室 |
| **FCC Part 15** | 强制 | 电磁兼容（EMC） | FCC 认可实验室 |
| **NERC CIP** | 强制（电网级） | 关键基础设施网络安全 | 第三方审计机构 |
| **CSA C22.2 No.107.1** | 强制（加拿大） | 逆变器/储能设备安全 | CSA |

### 2.3 其他市场

| 市场 | 核心认证 | 说明 |
|------|----------|------|
| **澳洲** | AS/NZS 4777.2 | 分布式发电并网 |
| **日本** | JIS C 4412（<50kW）、JEAC 9701（>50kW） | 分功率等级 |
| **韩国** | KC 认证 + 电网公司测试 | 需本地代理 |
| **台湾** | IEEE 1547（并网）+ 台电公司验收 | 参考 TCC 储能路径 |

## 三、国内外认证策略建议

### 3.1 先国内后国际（推荐路径）

```
第一步：国内 CMA+CNAS 报告（GB/T 42726-2023）
    ↓
第二步：基于国内报告数据，补充测试 IEC 61850、IEC 62443
    ↓
第三步：CE Mark（EMC + 安全指令）
    ↓
第四步：目标市场特殊认证（VDE/UL/AS/NZS 等）
```

**优势**：
- 国内测试数据可被国际机构部分采信，节省重复测试费用
- 国内项目先落地，产生现金流后再投海外认证
- 中国电科院 / TÜV 莱茵等具备双资质，可一测多证

### 3.2 直接出海路径

若产品一开始定位出口：

```
并行推进：
├─ CE Mark（EMC + LVD + RoHS）
├─ IEC 62443-3-3 SL2（网络安全，欧洲必做）
├─ IEC 61850（通信协议一致性）
└─ 目标国并网认证（VDE / UL / 等）
```

## 四、Cot 项目 EMS 产品认证建议

Cot 是**光储柴微网**场景，EMS 产品认证时需要额外关注：

| 特殊能力 | 认证关注点 | 建议 |
|----------|------------|------|
| **多模式切换**（并网/离网/并柴发） | 切换逻辑验证、切换时间测试 | 在 GB/T 42726-2023 测试基础上，要求机构增加模式切换专项测试 |
| **VF 控制** | 离网/VF 模式下的调压调频性能 | 引用 GB/T 36274-2018《微电网 EMS 技术规范》作为补充依据 |
| **柴发冷启动联锁** | 启动逻辑、保护配合 | 提供柴发接口协议，要求联调测试 |
| **SOC 均衡（双簇）** | 簇间均衡算法有效性 | 测试报告中体现均衡策略验证 |

## 五、送检准备清单

### 5.1 文档资料

```
□ 产品技术规格书（硬件配置、软件功能、接口清单）
□ 软件著作权证书（如有）
□ 用户手册 / 操作手册
□ 通信协议说明书（Modbus 点表、IEC 104 规约、IEC 61850 ICD 文件）
□ 系统架构图（网络拓扑、冗余配置）
□ 功能列表对照表（对照 GB/T 42726-2023 条款逐项对应）
□ 自测报告（工厂内部测试记录，加速第三方测试进程）
□ 委托测试合同 + 保密协议（NDA）
```

### 5.2 样机准备

```
□ EMS 工控机 / 服务器（与量产版一致）
□ 交换机、防火墙等配套网络设备
□ 模拟 PCS/BMS 的测试工装（或真实设备）
□ 模拟调度主站的测试软件
□ UPS（若产品标配）
□ 屏柜（若整机送检）
```
